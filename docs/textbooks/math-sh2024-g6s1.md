## 各章知识范围

根据各章"内容提要"页（第 52、77、108、140 页）整理，是出题时判断是否超纲的依据。原图在 `pic/6_1/p*.jpg`。

### 第 1 章 有理数

- 概念：有理数（能写成 $\frac{b}{a}$，a、b 为整数且 a ≠ 0 的数）、整数（正整数、零、负整数）、数轴、绝对值（数轴上的点到原点的距离）、相反数（绝对值相等、符号不同）
- 运算：加法法则（同号、异号、与 0 相加）、减法（加上相反数）、乘法法则、除法（乘以倒数，除数不为 0）、乘方、混合运算
- 运算律与自然数相同（交换律、结合律、分配律）
- **内容提要没有提到**：科学记数法、近似数。先不考，确认后再加

### 第 2 章 简单的代数式

- 概念：代数式（用运算符号或括号把数、字母连接而成的式子）、代数式的值（用数值代替字母后计算）、一次式、同类项、合并同类项
- 合并同类项：系数相加，字母不变；常数直接相加
- **内容提要没有单独列出**：去括号。第 3 章解方程要用到去括号，所以应该在 2.3 或 3.2 中学过，可以在第 3 章使用；2.3 里出去括号的题要谨慎

### 第 3 章 一元一次方程

- 概念：方程（含未知数的等式，未知数又叫元）、方程的解、解方程、一元一次方程（一般形式 ax + b = 0，a ≠ 0）
- 等式性质：两边同加（减）同一个数、同乘同一个数、同除以同一个不为 0 的数，等式仍成立
- 解法的一般步骤：**去括号、移项、合并同类项，整理成 ax = b（a ≠ 0），两边同除以 a**
- **内容提要没有"去分母"这一步**：含分数系数的方程可以用等式性质（两边同乘）来处理，但不作为基础题
- 应用：设未知数，列方程，解方程

### 第 4 章 线段与角

- 概念：线段、两点间的距离（连接两点的线段的长度）、线段的中点、射线、角（有公共端点的两条射线，也可以看成射线绕端点旋转而成）、角平分线
- 比较大小：线段的长短、角的大小，都可以直接比较或度量
- 画图：画一条线段等于已知线段，画线段的和、差、倍，画线段的中点；画一个角等于已知角，画角的和、差、倍，画角平分线（做题时改成计算和推理，不考作图操作）
- 基本事实：经过两点有且只有一条直线；两点之间线段最短；同角（等角）的余角相等；同角（等角）的补角相等
- **内容提要没有提到**：对顶角（可能在下册，先不考）。度分秒换算没有列出，但属于"角的度量"的常规内容，可以考，不过要在知识点里讲清楚
