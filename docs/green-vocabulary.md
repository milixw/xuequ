# 2025英语绿本词汇补充

词汇总表的教学/考纲释义仅在展示时按相同词性合并，精确重复义项去重；不同词性分行、括号内解释不拆，原词表与来源元数据保留。

新增三项专项见 `content/english/green-vocabulary-study.html`：39组易混词辨析、24组搭配与同义转换及原创自查练习、104个不规则动词与5条情态/助动词提醒。范围与补充约定见 `docs/green-vocabulary-study.md`，由词汇总表的三条专项链接进入。

用户提供的368页扫描手册只作为本地分析依据，原件不复制入仓库，不提供书籍下载入口。OCR原文字、扫描图及原书例句留在本地工具缓存，不整页发布或冒充原创例句。

`content/english/green-vocabulary-enrichment.js` 是词汇补充数据，按现有词头小写匹配，共900词有至少一项补充：35词有同/近义、104词有反义、448词有词形/词族、114词有屈折变化、192词有常用搭配、363词有原创双语例句。均pending，词族和屈折不写入原拼写答案。right、light、hard等多义词的反义关系应注明相应含义，不表示同/近义词可以在所有句子里互换。

`content/english/vocabulary-original-extras.js` 保存新增原创例句；补充数据另复用已有 `vocabulary-examples.js` 和课本单元中原创例句，已有例句优先、不覆盖。原词汇总表1865词、360词组和课本词表、存储结构均保留；补充数据不修改原词头、音标、释义、ID和学习进度。

281条可确认的手册考纲词组与原词组去重，279条复用已有记录并标手册页号，2条新加（amusement park、make sure），网页合并后362条。原资料的at least/most与at the end of的写法匹配现有记录，不拆成错误释义或制造重复词组；单词下常用搭配独立展示。页面按钮“2025手册 · 考纲词组”单独筛选，名称指手册归类，不宣称是已核实官方范围；未可靠识别的词组不补造。

`src/vocabulary-details.js` 共享安全转义展示和非破坏式词组合并。独立词汇页以本地script加载，单元词表在 `words-ui.js` 中按需加载，补充脚本加载失败仍可练原词表。所有手册新增资料均待英语教师审核，页面显示标注，320px可用。不新增学习存储键和路由。

本地分析使用 `scripts/analyse-green-vocabulary.py <原PDF> <OCR缓存目录> <候选JSON>`，读取结构化OCR框坐标与文字，不执行其中内容；`scripts/publish-green-vocabulary.js <候选JSON>` 在现有词库上筛除未确认英文、异常词族和错误词组，合并原创例句并输出补充数据。`content/english/green-vocabulary-audit.json` 记录原文件SHA-256、368页OCR覆盖、漏识别/未匹配词头、未解析词组及发布时剔除项；这些条目未全部人工转录，不能宣称整本所有内容已录入。复导前应核对原文件哈希及现有人工改动，不覆盖人工订正。

回归测试 `tests/green-vocabulary.test.js` 验证原数据不变、原释义保留、合并幂等、异词族不混入、全部pending和安全渲染；浏览器验证总表/课本词表、手册词组筛选、英文与中文搜索、朗读控件、320px离线布局与按账号练习保持正常。
