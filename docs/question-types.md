# 题型台账

记录**每个套路用在哪里、用了几次**，用来规划两件事：核心题型要**有计划地复现**，直到学生真正掌握；一次性的巧题不要换个数据又出一遍。另有一份**还没用过的套路池**，出题时可以从里面挑。

- **开工前**：查"套路总表"。本节要用的核心题型，看前面用过几次、用的什么情境，这次换情境或加一步再出；一次性的巧题，确认没出过
- **收工后**：把新用的套路补进总表和明细，标注定位和来源；核心题型的复现记在原来那一行的“用在”里
- 跨会话也靠这些文件传递：新会话读本册和前置册的文件，就知道前面用过什么

## 一、套路总表（按学科、按册分文件）

"用在"列里 `1.2-c03` 表示 1.2 节挑战第 3 题。

**定位**列分两种：

- **核心**：学生必须掌握的基本方法和常见题型（分类讨论、整体代入、系数为 0 定参、配方、行程和工程应用、正误辨析等）。要在不同小节、不同章节**有意复现**，每次换情境、换坑，或者多叠一步，不要原样重出
- **一次性**：巧妙的构造、名题的结构、特定数据才成立的技巧。出过一次就够，后面别再换数据重出

判断重复时分清两件事：

- **有计划的复现**（可以）：核心题型在新情境里再考一次，或者在原来基础上加一个环节
- **换数版**（不可以）：题型、情境、步骤都一样，只换了数据。挑战题是本节扩展题的换数版，一律不合格
- 同一小节内：基础档可以有两道同一核心题型的题，但两道的坑要不同；扩展档、挑战档里同一套路只出一次

## 三、外部参考资料（教辅等）

后期补充教辅资料时按这里的规则处理。

**放在哪**
- 原始资料（PDF、扫描件、照片）：放 `refs/`，**不入库**（和 `pic/` 一样，体积大且是他人版权内容）
- 提炼出的笔记：写成 `docs/references/<来源简称>.md`，入库

**怎么用**
- 学的是**题型结构、难度标尺、常见易错点、命题角度**，不是题目本身
- 提炼时用自己的话记录，例如"某教辅在一元一次方程一章用了『由错解反推原题』，难度约等于期末压轴填空"
- 出题时必须**换情境、换数据、换问法**，并照常跑 `verify` 和盲解复核
- 学到的新套路登记进对应册文件的"套路总表"，来源列写明出处，例如"参考《XX》第 3 章"

**红线**
- 不整题照抄题面、数据和措辞，不批量导入
- 不把教辅原文写进知识点卡片或解析
- 产品中不声明与任何教辅、出版社的关联

**难度校准的用法**
教辅通常分基础／提高／竞赛三档。拿到资料后，可以从它的"提高档压轴题"和"竞赛档"各取几道，对照本项目的扩展档和挑战档，判断我们的标准是偏松还是偏紧，必要时更新 AGENTS.md 的难度表。
