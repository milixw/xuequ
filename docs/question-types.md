# 题型台账

记录**已经用过的套路**，避免新小节重复；同时维护一份**还没用过的套路池**，出题时可以从里面挑。

- **开工前**：查"套路总表"，确认本节要用的思路没被用滥；挑战题尤其不能和同节扩展题撞
- **收工后**：把新用的套路补进总表和明细，标注来源
- 跨会话也靠这份文件传递：新会话只要读它，就知道前面用过什么

## 二、按小节明细

只列扩展和挑战题（基础题不易撞车）。

### 1.1 有理数的引入
- 扩展：动点到原点距离相等 / 相反数两点间整数点计数 / 折叠 / 符号多选 / 爬行规律计数 / 中点三情况 / 绝对值求距离 / 两层距离分类 / 距离之比 / 绝对值+平移+相反数
- 挑战：折返停留动点（分段）/ 交替对称点（周期 6）/ 线段覆盖整数点（含参、边界）/ 六数排序与"不存在"论证 / 三点距离和（最值、含参、解的个数）

### 1.2 有理数的加法与减法
- 扩展：分组配对求和 / 绝对值条件求值 / 折返动点 / 两点距离和含参 / 绝对值混合计算 / 三绝对值筛选 / 添±号最小非负和 / 周期部分和 / 新运算含反推 / 递推数列周期 6
- 挑战：多点距离和（最小值、含参、去掉一项最优）/ 双向折返动点（无解段）/ 添±号可取值个数（奇偶 + 构造）/ 格点计数（对称法）/ 动点 + 距离和分段

### 1.3 有理数的乘法与除法
- 扩展：符号函数求和 / 裂项（奇数间隔）/ 连乘约分 / 选数求 $\frac{ab}{c}$ 最值 / 因数枚举 / 多绝对值筛选 / 倒数与相反数代入 / 新运算反推（含绝对值分类）/ 符号多选（3 变量）/ 积为定值求商的最值
- 挑战：非负性 + 裂项 + 排除分母为 0 / 取数相乘的计数与最值 / 新运算发现倒数规律 / 倒数递推周期（积、和、反推 n）/ 单位分数构造

### 1.4 有理数的乘方
- 扩展：概念多选 / 乘方混合计算（3 道）/ $-1<a<0$ 的排序 / 平方与绝对值筛选 / 新运算反推（平方两解 vs 立方一解）/ $a^3=a$ 类分类 / 平方数与六次方数计数 / 逐步抵消
- 挑战：$k^k$ 的个位（双层周期）/ 乘方符号多选 + 绝对值 / 弹跳小球（极限、估算、反推）/ 细菌分裂（不变量）/ 等比数列相邻和（奇偶定位）

### 1.5 有理数的混合运算
- 扩展：绝对值与平方筛选 / 立方和规律 / 混合计算（3 道）/ 数轴非负性 + 距离 / 交错数列和与比 / 整体代换 / 符号函数 / 基准数应用 / 分类但结果唯一
- 挑战：距离和最小 + 区间上 $x^y$ 的最值 / 三角数阵 / 三因数裂项 + 阈值 / 填运算符最值 / 裂项构造推广到平方和

## 三、还没用过的套路池

做后面章节时优先从这里挑。带 ※ 的是复核认为"叠加环节"容易做足的类型。

**第 2 章 简单的代数式**
- 用字母表示图形规律（第 $n$ 个图形要几根火柴）※
- 代数式求值的整体代换（已知 $a+b$ 求含 $a+b$ 的式子）※
- 项数、系数、次数的辨析与陷阱
- 含字母的分类讨论（$a$ 的符号未知时化简绝对值）※
- 新定义运算含字母，再反推参数 ※
- 用代数式表示实际数量关系（计费、面积、增长）

**第 3 章 一元一次方程**
- 行程：相遇、追及、环形、流水 ※
- 工程、浓度、年龄、数字问题（数位交换）※
- 分段计费（阶梯水电费、快递、出租车）※
- 方案设计与最优（几种买法哪种省）※
- 含参方程解的讨论（无解、解为整数、解为正数）※
- 绝对值方程的分类讨论 ※
- 由错解反推原题（"把 $+3$ 看成 $-3$"）

**第 4 章 线段与角**
- 线段中点与比例、$n$ 等分点
- 角平分线、角的和差倍
- 钟表时针分针夹角 ※
- 方位角
- 折叠与旋转中的角 ※
- 动点在线段或角上运动 ※
- 几何计数（$n$ 个点的线段条数、$n$ 条射线的角个数）※
- 余角补角的多层推理
- 无图题：按位置关系分类讨论 ※

**通用（各章都能套）**
- 阅读理解题：先给一段新知识，再用它解题 ※
- 逆向思维：给出结果反推条件 ※
- 数表、数阵定位
- 最值与取值范围
- 存在性论证（说明某种情况不可能）※

## 四、外部参考资料（教辅等）

后期补充教辅资料时按这里的规则处理。

**放在哪**
- 原始资料（PDF、扫描件、照片）：放 `refs/`，**不入库**（和 `pic/` 一样，体积大且是他人版权内容）
- 提炼出的笔记：写成 `docs/references/<来源简称>.md`，入库

**怎么用**
- 学的是**题型结构、难度标尺、常见易错点、命题角度**，不是题目本身
- 提炼时用自己的话记录，例如"某教辅在一元一次方程一章用了『由错解反推原题』，难度约等于期末压轴填空"
- 出题时必须**换情境、换数据、换问法**，并照常跑 `verify` 和盲解复核
- 学到的新套路登记进上面的"套路总表"，来源列写明出处，例如"参考《XX》第 3 章"

**红线**
- 不整题照抄题面、数据和措辞，不批量导入
- 不把教辅原文写进知识点卡片或解析
- 产品中不声明与任何教辅、出版社的关联

**难度校准的用法**
教辅通常分基础／提高／竞赛三档。拿到资料后，可以从它的"提高档压轴题"和"竞赛档"各取几道，对照本项目的扩展档和挑战档，判断我们的标准是偏松还是偏紧，必要时更新 CLAUDE.md 的难度表。
