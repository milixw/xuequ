# 上海历年听力音频压缩（2026-10-18）

14份年度音频：101.08 MiB → 56.51 MiB，减少44.1%。另处理页面原先引用的2025年MP4和2026年MP3；合计16份：120.00 MiB → 64.49 MiB，减少46.3%。

播放容器统一为M4A。高码率音频使用AAC-LC、40 kbps、单声道、24 kHz；2024、2025年度合集音轨本身已是低码率，只重封装，不再次有损编码。旧2025年MP4去除视频，仅保留音频；它与合集录音保留为两个独立文件，不替换录音版本。

没有裁剪、加速、变调或降噪。解码检查所有文件无错误，新旧时长差小于0.15秒；Chrome在file://下验证全部16份文件可播放，且可跳到中段和末尾。此为编码和播放检查，不代表已逐题试听或教师审核；有损编码也不等于音质无损。

原版已按年份、原文件名及SHA-256备份到下载目录内“上海中考英语听力/压缩前备份-20261018”，该目录另存准备好的压缩文件和compression-records.json。备份不进入网站包。网站中`listening-audio.json`的`compression`保存原版大小、哈希、时长及压缩方法，`legacyFiles`保存旧页面录音的独立来源版本。

工具准备与替换分开：

```text
python scripts/compress-shanghai-listening.py <ffmpeg路径> <仓库外备份目录>
python scripts/compress-shanghai-listening.py <ffmpeg路径> <仓库外备份目录> --apply
```

首步保存并校验备份，准备新文件、完整解码检查；浏览器确认播放后再执行第二步。应用时拒绝覆盖不同的压缩版本，验证备份和成品哈希后才移除仓库内原版，原题和题目ID不改。旧资料导入根据原音频哈希复用相同录音版本的压缩文件，不重新拷入大文件。
