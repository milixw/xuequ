# 参考资料笔记

放从教辅、真题卷等外部资料里提炼出来的**笔记**，一个来源一个文件，比如 `docs/references/xx-jiaofu.md`。

原始资料（PDF、扫描件、照片）放项目根目录的 `refs/`，不入库。

## 为什么只放笔记

外部资料有版权，不能整题照搬。我们要学的是命题思路和难度标尺，学完写成自己的话即可，原文不进仓库、不进题库。

## 笔记写成什么样

每份笔记建议包含四部分：

```markdown
# 《资料名称》（年级 / 章节范围）

## 基本信息
- 类型：教辅 / 真题卷 / 竞赛题集
- 对应章节：比如六年级上册第 2 章
- 难度分档：它自己怎么分的（基础 / 提高 / 竞赛）

## 题型清单
用自己的话概括，每条一行，注明它放在哪一档：
- 用字母表示图形规律（火柴棒、点阵）——提高档
- 由错解反推原题——提高档压轴
- 含参方程解为正整数——竞赛档

## 难度标尺参考
挑 2～3 道它的压轴题，说明思维环节有几个、大概几步，
用来对照本项目的扩展档和挑战档是偏松还是偏紧。

## 可借鉴的点
- 命题角度、易错点设计、情境包装
- 明确写出哪些**不能**直接用（比如某题已经是流传很广的原题）
```

## 用完之后

把学到的新套路登记进 `docs/question-types.md` 的"套路总表"，来源列写明出处。出题时必须换情境、换数据、换问法，并照常跑 `verify` 和盲解复核。
