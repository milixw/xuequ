# 天平解方程

日期：2026-09-24

## 目标

挂在六上 3.2「一元一次方程及其解法」上的动手玩游戏。把方程摆成天平，只允许“两边同时”操作，让学生亲手体会等式的性质、移项为什么变号、去括号为什么每一项都要乘。

和 24 点、取石子不同，它和课本联系紧，所以**不放首页“趣味玩法”**，入口在：

- 小节页 3.2：知识点和练习之间的“动手玩”卡片
- 册页：3.2 那一行下面的“玩”行，显示已过关数

页面在应用内渲染，路由 `#/g/balance/<关卡ID>`，顶栏返回键回到 3.2 小节页。以后挂在别的小节的游戏也照这个做法：在 `catalog.js` 小节条目上写 `games: ['<ID>']`，游戏脚本在 `index.html` 里加载，注册到 `window.Games[ID]`（`{ id, title, section, desc, mount(main, levelId), progress() }`）。

## 天平和方程的对应

| 天平上 | 方程里 |
|---|---|
| x 盒子（蓝色方块） | $x$ |
| 砝码 | $1$ |
| x 气球（往上拉） | $-x$ |
| 气球 | $-1$，和一个砝码抵消 |
| 袋子，里面装着比如 $x+2$ | 括号 $(x+2)$，几个袋子就是几倍 |
| 袋子气球 | $-(x+2)$ |

操作只有三种，都作用在两边：

1. **两边同时放上 / 拿走** n 个某种东西（等式性质 1）。拿走的比某边有的多时，多出来的部分变成相反的东西（拿走砝码不够就出现气球），并提示“不够的部分就等于放上气球”
2. **两边同时除以 k**（等式性质 2），k 取 −12～−1、2～12；有一项不能整除就拦下并说明。除以负数时砝码和气球互换
3. **打开某一边的袋子**（去括号），重量不变，天平不动。只剩 1 个袋子时自动打开，不算步数；−1 个不自动打开，因为变号正是要练的

每次操作先改左边，天平按真实轻重倾斜，式子显示成 `<` 或 `>`，再改右边回平，演示“只动一边等式就不成立”。

目标：一边只剩一个 x 盒子，另一边只有砝码或气球。完成后显示 $x$ 的值、代回原方程检验、步数评星（最少步数 3 星，多 1～2 步 2 星，其余 1 星）。

## 关卡

3 章 13 关，★ 为挑战关，挑战关要用最少步数才算过关。数据只写题面和天平摆法，最少步数由 BFS 算。

| 章 | 关卡 | 练什么 |
|---|---|---|
| 1 天平和等式 | $x+3=8$、$3x+2=14$、$4x+1=x+10$、★$2x+11=5x+2$ | 等式性质、移项；x 可以留在右边 |
| 2 气球：负数 | $x+7=3$、$2x-5=9$、$-2x=10$、$5-2x=x+11$、★$3-5x=13-3x$ | 负数结果、加上相反数、除以负数 |
| 3 袋子：括号 | $2(x+3)=14$、$3(x-1)=x+7$、$-2(x-4)=x+2$、★$5(x+2)=2(x+2)+9$ | 去括号、负号在括号外、整体思想 |

关卡避开了 3.2 知识点卡片和题目里的方程。3-1 和 3-4 不打开袋子反而更快（2 步、3 步），挑战关逼学生把袋子看成整体。

## 求解器（`src/games/balance/solver.js`）

- 局面 `[左, 右]`，每边 `{ x, n, b }`：x 盒子、砝码、袋子的个数，负数表示气球
- `shortest()`：BFS 求最少步数。候选操作只取“把某一边的某种东西消成 0”、按公因数整除、打开袋子；提示也用它，按“先开袋子、数小的先消、正数除法优先”的顺序给出比较自然的一步
- 测试用全部操作（任意个数、任意除数）穷举到“最少步数 − 1”层，确认没有更短的走法
