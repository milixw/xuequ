# 英语单元按技能重组：单词、语法、语音

状态：设计稿，维护者已确认待定事项（2026-10-08）；开工前不动代码。

## 背景

英语八上现在每个 Unit 一个小节（`english/sh2022/g8s1/1.1`～`6.1`），沿用数学的“知识卡 + 基础/扩展/挑战选择题”结构。问题：

- 单词只在短文里出现一次，没有复习、拼写，也不知道学生记没记住
- 语法只有选择题，只考“认得出”，不考“写得对”
- 课本每单元的 Pronunciation file 没有对应内容
- 数学按解题步数分难度，英语更自然的递进是“认识 → 会用 → 能产出”

## 目标与范围

- **适用所有年级**：本设计是英语各册（六上～九下，`sh2022` 教材）的统一结构，数据格式和存储从第一期起就不分册
- **重点是课本**：单词、语法、语音的范围都以本册课本为准；兼容上海中考 1600 词的方式是给单词打标记、做一个可选的扩展复习，不做全量词库背诵
- **每天约 10 分钟**：复习队列、每日新词数按这个时长设计
- **首期做六上 Unit 1**（维护者 2026-10-08 由八上改为六上），用它跑通后再铺到其他单元和其他册

不做：发音评分（语音识别依赖国外服务，国内手机和 `file://` 下都不可靠）、开放写作自动判分、课文原文收录。

## 单元结构

一个 Unit 对应 `catalog.js` 的一章，章下分几个板块：

| 板块 | 形式 | 说明 |
|---|---|---|
| 阅读与语法入门 | 现有小节 `<单元>.1` | 原创短文、重点词、知识卡、16 道选择题、2 道错题库例题，**保持不变**，ID 不动 |
| 单词 | 单词模块（新） | 本单元课本词表，学习 + 测试，进入全局间隔复习 |
| 语法练习 | 小节 `<单元>.2`（新） | 多题型：选择、填词形、合并句子、改错、句型转换、造句 |
| 语音与听力 | 小节 `<单元>.3`（新，第三期） | 本单元 Pronunciation file 的知识点：重音、辨音、听写 |

语法练习和语音听力仍是 `Content.section`，走现有的小节页、做题引擎和进度存储，只扩展题型。单词不是“一组题”，而是“一组词各自的记忆状态”，所以单独做模块。

册页面（`#/v/<册ID>`）的每一章下面，在小节列表之外多显示一行“单词 · 已掌握 n / 共 m”（掌握态和认读态都算），点进单元单词页。

## 一、单词

### 词表数据

来源：refs 里的课本 PDF 的词汇表，用导入脚本按单元导出。单词、音标、词性、课本释义直接使用（维护者已同意）；例句全部 AI 原创。

文件：`content/english/words/<教材>-<册ID>.js`（如 `sh2022-g8s1.js`），用 `<script>` 按需加载，在 `src/app.js` 的 `DATA_SCRIPTS` 登记。

```js
Words.volume({
  id: 'english/sh2022/g8s1',
  source: { kind: 'textbook-glossary', pages: '…', sha256: '…' },  // 导入脚本写入
  review: { status: 'pending' },
  units: [{
    no: 1,
    title: 'Water',
    words: [{
      w: 'reuse',                        // 词头，也是记忆进度的键；短语写 'as soon as'
      ipa: '/ˌriːˈjuːz/',
      pos: 'v.',
      zh: '再次使用；重复利用',
      page: 16,                          // 课本首次出现页码（导入）
      basic: true,                       // 课本词表粗体 = 课标三级词汇表的基本词汇（导入，按字体识别）
      note: '(pl. lives)',               // 可选：词表里括号中的补充说明，如复数、= 同义写法（导入）
      forms: ['reuses', 'reused', 'reusing', 'reusable'],   // 可选：常用变形，用于卡片展示和校验例句挖空
      ex: [                              // 原创例句，[[ ]] 里的文字就是 L4 的标准答案
        { en: 'We [[reuse]] the rainwater for the plants.', zh: '我们把雨水再用来浇植物。' },
        { en: 'Last week the club [[reused]] old bottles as flower pots.', zh: '上周社团把旧瓶子再利用做成了花盆。' },
      ],
      core: true,                        // 导入时取 basic：课本粗体词要会拼写，非粗体只认读（只做 L1、L2）；教师审核时可调整
      exam: true,                        // 在上海中考词汇表里（导入时自动比对）
    }],
  }],
});
```

规则：

- 同一册里词头不重复；同一个词在不同册出现（如七上、八上都有 record），**记忆进度按词头全局共用**，释义按各册显示
- 课本词表粗体为课标基本词汇：导入时 `core` 取 `basic`，非粗体词 `core: false`，只认读、不出拼写题；教师审核时可调整个别词
- `ex` 是数组，每条恰好一处 `[[...]]`，其中文字必须是 `w` 或 `forms` 之一；例句不能取自课文
- 例句数量（决定内容生产量）：`core: true` 且有常用变形（动词时态、名词复数、派生词）的词 **2 条**，一条考原形、一条考最常用的变形；没有变形的词（介词、连词、固定短语）和 `core: false` 的词 **1 条**；最多 3 条。按八上每单元约 40～60 词估算，每单元约 70～90 条例句
- `exam` 由导入脚本对照中考词汇表自动生成，不手填
- 词表 JS 文件里 `Words.volume(...)` 括号内保持 JSON 格式，导入脚本按 JSON 读写；人工改过的释义加 `manual: true`，复导不覆盖

### 四种练法

| 级别 | 练法 | 判分 |
|---|---|---|
| L1 认义 | 看英文（可点 🔊）选中文，4 选 1 | 选项 |
| L2 回忆 | 看中文选英文；或只听发音选英文 | 选项 |
| L3 拼写 | 看中文、词性，可听发音，写出单词 | 严格拼写 |
| L4 用法 | 原创例句挖空，括号里给词头（如 `(reuse)`），填正确形式；多条例句按该词的作答次数轮换，保证原形和变形都考到 | 与该条例句 `[[...]]` 中的文字一致 |

干扰项在运行时生成：L1 取同单元、同词性的其他释义；L2 优先取拼写相近的词（编辑距离小），不足时取同单元的词。

拼写判分（新增 `answer.js` 的 `kind: 'en'`，语法题的填空也用它）：去掉首尾空格、多个空格合一、弯撇号转直撇号、不区分大小写、忽略结尾句号；连字符和空格**不**互相替换（如 well-known），确有多种写法时在数据里列出。字母错一个也判错，但反馈里标出错在哪一位，降低挫败感。

### 间隔复习

用分盒法（Leitner）：

| 盒 | 下次复习 | 这一盒出的练法（`core: true`） | `core: false` |
|---|---|---|---|
| 1（新词、答错） | 当天 | 先 L1，本轮结束前再出一次 L3 拼写 | L1 |
| 2 | 1 天后 | L3 拼写 | L2 |
| 3 | 3 天后 | L3 或 L4 交替 | — |
| 4 | 7 天后 | L4 或 L3 交替 | — |
| 5 | 15 天后 | L4 | — |
| 掌握 | 30 天后抽查一次 | L3 | — |
| 认读（只给 `core: false`） | 15 天、之后每 30 天见一次 | — | L1 或 L2，永不拼写 |

- **新词当天就要拼写一次**：`core: true` 的新词看完卡片先做 L1，本轮结束前再做一次 L3；L3 答对进第 2 盒，答错留在第 1 盒、第二天再出。这样第一次动笔不会拖到第 3 天，第 2 盒起每次复习都要拼写
- 答对升一盒。答错时：第 1、2 盒退回第 1 盒；第 3 盒及以上**降两盒**（如第 5 盒错了回第 3 盒），不一下打回原点，避免偶尔拼错一个字母就让第二天的队列暴涨。答错的词都在本轮结束前再出一次
- `core: false` 的词走第 1、2 盒后进入**认读态**，不进第 3 盒以上，也不进掌握态；认读态长期低频复习，只出 L1、L2，答错退回第 1 盒。上表“掌握”只适用于 `core: true`
- 学新词时先看卡片（词、音标、🔊、释义、例句）。卡片上有“我认识”按钮，点了跳过 L1、直接出 L3 拼写：答对**进第 2 盒**（1 天后再拼一次，再对才进第 3 盒），答错按正常新词留在第 1 盒。也就是说熟词至少要在两天里各拼对一次才能升到第 3 盒，乱点“我认识”再蒙拼写占不到便宜，也不用限制使用次数。`core: false` 的词点“我认识”改出 L2，答对进第 2 盒

### 每天 10 分钟

按选择题约 6 秒、拼写约 12 秒估算：一个新词（卡片、L1、L3）约 25 秒，10 个约 4 分钟；复习以拼写为主，平均约 10 秒一个，40 个约 7 分钟。满负荷约 11 分钟，所以到期复习多时新词要减半：

- **到期复习**：每天最多 40 个，按逾期天数从多到少排；超过 40 个的顺延到第二天，不一次堆给学生
- **新词**：默认每天 10 个，设置里可选 5 / 10 / 15；到期复习超过 30 个时，当天新词自动减半
- **新词从哪来**：默认取当前学期（`xq.grade`）第一个还有未学词的单元；单元单词页可以手动“学这一单元”
- 首页显示今日任务卡：“今天复习 n 个、新学 m 个，约 x 分钟”。做完显示完成，可以选择再来一组
- 中考词扩展：中考词表里、但学生已学课本词表中没有的词，作为可选的“中考词加练”，**不进入每日默认任务**，第一期不做

### 存储

`xq.words.v1.<归属>`，通过 `LearningStore` 按账号隔离：

```js
{
  words: { 'reuse': { box: 3, due: '2026-10-11', seen: 4, wrong: 1, last: '2026-10-08' } },  // box：1～5，'M' 掌握，'R' 认读
  days: { '2026-10-08': { reviewed: 32, learned: 10, wrong: 5, ms: 540000 } },  // 只保留最近 90 天
  settings: { newPerDay: 10, unit: 'english/sh2022/g8s1/1' },
}
```

日期用本地日期字符串，不用时间戳，避免跨时区和跨午夜的边界问题。

### 发音

把中考词汇表页面里的朗读逻辑抽成 `src/speech.js`，单词模块、语法和语音小节共用：优先用设备英文语音，没有时用有道在线读音；离线又没有英文语音时，🔊 按钮变灰并提示“这台设备暂时不能朗读”，L2 的“听音选词”自动换成“看中文选词”。

## 二、语法练习小节（`<单元>.2`）

- 内容是 `Content.section`，没有 `reading`；知识卡引用 `content/english/knowledge.js` 的条目（新增 `knowledgeRefs: ['<知识点ID>']`），不在两处各写一套讲解。缺的语法点补进 `knowledge.js`，错题库和单元共用
- 题目 ID 照通用规则 `<小节号>-<档位首字母><序号>`，`level` 沿用 basic / extended / challenge，**英语界面显示为“辨认 / 运用 / 产出”**
- 每节 15 道左右：辨认 5、运用 7、产出 3（测试按英语单独校验，不套数学的 5/6/5 或 20 题）

题型：

| 题型 | 实现 | 示例 |
|---|---|---|
| 选择 | 现有 `choice` | 选连词 |
| 填词形 | `fill` + `kind: 'en'` | The tap is (leak) ____. |
| 合并句子 | `fill` + `kind: 'en'`，`answer` 列出多个可接受句子 | 用 as soon as 合并两句 |
| 改错 | `choice`（选出有错的划线部分）+ `fill`（写改正） | 两空都对才算对 |
| 句型转换 | `fill` + `kind: 'en'`，每空一词 | 同义句填空 |
| 造句（产出） | 新题型 `open`：给参考答案和自查要点，学生自己勾“符合 / 不符合” | 用 unless 写一条校园节水建议 |

- 整句答案除拼写规则外，还忽略结尾标点、句首大小写；每道整句题至少列出 2 个可接受答案，教师审核时补充
- `open` 题自评不计入正确率，只计“已完成”

## 三、语音与听力小节（`<单元>.3`，第三期）

范围取自本单元 Pronunciation file，用导出脚本按页导出确认。题目可带 `audio: { text: '…' }`，题干旁显示 🔊，用 `src/speech.js` 朗读。

题型：单词重音位置（选择）、划线部分读音是否相同（选择，中考常见题型）、相近音辨析（听音选词）、句子听写（`fill` + `kind: 'en'`）。不做跟读评分；第三期再评估是否加“录音后回放、与标准音自己对比”，在不支持录音的设备上隐藏。

## 内容生产流程

1. **课本资料**：`docs/textbooks/english-sh2022-<册ID>.md` 补上 PDF 路径、页码换算，以及每单元的词汇表页、Pronunciation file 页、Grammar file 页；`scripts/textbook-text.py` 扩展为支持英语资料文件
2. **词表导入**：新增 `scripts/import-english-words.py <册ID>`，读课本词汇表，生成词头、音标、词性、释义、单元、`core`，绑定来源 SHA-256；比对中考词表生成 `exam`。复导时保留人工修改，不覆盖已有的例句和 `forms`
3. **AI 补充**：例句、`forms` 由 AI 写，`review.status: pending`。自动检查：每条例句恰好一处挖空、挖空词属于 `w` 或 `forms`、例句条数符合上面的规则、例句不与课文重复（与导出的课文文字做 8 词以上的重叠检查）
4. **语法题、语音题**：按 `content/english/AGENTS.md` 的出题标准写，英语教师审核，不用数学的盲解记录冒充语言复核
