# 首页改版：今天 + 学科

2026-10-20 与维护者讨论确定，当天按四步实施完（实施时和原稿不同的地方已改在正文里）。

## 背景与目标

现在的首页从上到下分五个区：本学期课本、练习、复习资料、中考真题、趣味玩法。用的时候有几个问题：

1. **两种分法混在一起**：区是按“做什么”分的，区里面又按学科分，同一个学科的入口散在好几个区。以六年级上册的英语为例：课本卡片和“本册课本录音”在“本学期课本”，“英语单词”“英语试题库”在“练习”，“英语学习大纲”“课本资料”在“复习资料”，英语中考真题在“中考真题”。学生想的是“我现在学英语”，却要在四个区里找。
2. **没有主次**：一屏二十多个入口分量差不多，打开后最该做的事（接着上次学、今天的单词）不在最上面。
3. **和年级对不上**：选的是六年级上册，看到的语文资料却全是中考级别的考纲和应考手册；趣味玩法里有八下、七下才用得上的游戏；中考真题对六年级也太早。
4. **三个“考试”分不清**：“试卷”其实是按小节的限时测试，另外还有“模拟考试”和“中考真题”。
5. **五种卡片样式**：课本大卡、两列小格、带图标的列表行、学科小块、游戏宫格，看起来像几个页面拼在一起。
6. **入口是写死的**：只有课本走 `content/catalog.js`，复习资料（`NOTE_GROUPS`）、游戏（`FUN_GAMES`）、单词、题库、真题入口都写在 `src/app.js` 的 `home()` 里，加学科、加资料都要改首页代码。

这次改成：**首页只放“今天”和学科入口，每个学科一个学科页，这个学科的东西都在学科页里。**

确定的三点：

- 走“今天 + 学科”的方向，不在现有五区上做减法
- 没有课本的学科（语文、物理、化学）也在首页给一张学科卡片
- 界面上的“试卷”改名“小节测试”（只改文字，路由 `#/exam` 不变）

不变的：已有路由、题目 ID、小节 ID、所有存储键的格式，学生进度不受影响；零构建、不引入框架。

### 今天

一个列表块，按下面顺序出现，**没有的行不显示**：

| 行 | 什么时候出现 | 点了去哪 | 数据 |
|---|---|---|---|
| 接着学 | 记录过上次打开的小节，且这一节还在目录里 | 那一节 `#/s/<小节ID>` | 新键 `xq.lastVisit.v1.<归属>`，见下文 |
| 今日单词 | 本学期有英语课本词表，今天还有要做的 | `#/words` | `Words.plan(...)` 算今天的任务数和预计用时 |
| 模拟考试进行中 | `xq.mockExam.v1` 里有 `startedAt` 且还没到时间 | 对应卷子 `#/mock/<卷集ID>/<卷ID>` | 复用 `MockExam.remainingSec` |

三行都没有时（第一次打开），显示一行提示：“从下面选一个学科开始”。

**接着学**：在小节页和做题页（`#/s/…`、`#/q/…`）打开时记下小节 ID 和时间。按账号归属，经 `LearningStore`，和其他学习数据一样未登录的访客单独一份。只存最近一次，不做历史列表。

```
xq.lastVisit.v1.<归属>  →  { section: '<小节ID>', at: <毫秒时间戳> }
```

真题卷（`#/e/…`）、英语中考题这些暂时不记，它们有自己的入口；以后要记时再加 `kind` 字段。

**今日单词**：`WordsUI.todaySummary()` 用 `<script>` 加载各册词表（不加载 2025 手册补充，文件大且首页用不到），算出今天复习、新学几个和预计分钟数；没有本学期词表、加载失败或今天没有任务时不显示这一行。不为首页另做一份数据。“今天”的三行先放占位，异步结果回来按顺序填进去。

### 学科卡片

- **哪些学科出现**：目录里有本学期课本的学科，加上有资料或真题入口的学科（见下文“学科登记”）。按 `catalog.js` 里的顺序排：数学、英语、语文、物理、化学
- 卡片写三行：学科名；本学期那一册的册名，没有课本的写“复习资料”或“中考真题”；第三行有课本的写“已答对 n 题”，只有资料的写“另有中考真题”（实施时英语也用答对题数，没有为卡片另外加载词表算单词掌握数）
- 一个学科本学期有多册（比如数学六年级上册和六年级衔接），卡片只写第一册的册名，第三行写“共 2 册 · 已答对 n 题”（写在册名后面在 320px 宽时会折行），进学科页再分
- 两列网格，320px 宽时也是两列，卡片高度一致

### 趣味玩法

保留在首页，因为它不完全属于某个学科的某一册，而且是学生愿意点的东西。改动：

- 每个游戏标“从哪个学期起适用”（现在的 `when` 文案保留，另加 `from: 'g6s1'` 这样的学期 ID）
- 首页只显示 `from` 不晚于当前学期的游戏，加上“不限年级”的；其余收在“全部 ›”里（进 `#/games`，列出全部，样式同现在的宫格）
- 数学学科页的“玩法”组也列出同样的内容，和小节页里挂的“玩”行互不影响

## 学科页 `#/subject/<学科ID>`

`#/s/` 已经是小节页了，所以学科页用 `#/subject/`。学科 ID 沿用目录里的 `math`、`english`，新增 `chinese`、`physics`、`chemistry`。

页面统一分几组，每组都用现在“复习资料”那种带图标的列表行（`note-row`），**没有内容的组不显示**：

| 组 | 内容 |
|---|---|
| 本学期课本 | 本学期这一科的各册卡片（沿用现在的课本卡片）；英语已解锁时加“本册课本录音”；最后一行“其他册 ›”，展开后列出这一科的全部册 |
| 练习 | 小节测试、英语单词、英语试题库、七天复习计划 |
| 资料 | 学习大纲、课本资料、文言实词虚词、古诗文联动注释等 |
| 考试 | 模拟考试（有私有资料时）、中考真题 |
| 玩法 | 只有数学有：同首页的游戏宫格 |
| 中考专区 | 见下文“按年级显示” |

以英语为例：

## 学科登记（把写死的入口搬到数据里）

在 `content/catalog.js` 的每个学科上加 `resources` 列表；没有课本的学科也加一个条目（`editions: []`）。首页、学科页、“今天”都从这里生成，`app.js` 里不再有 `NOTE_GROUPS`、`FUN_GAMES` 和写死的练习、真题入口。

```js
{
  id: 'english',
  name: '英语',
  color: '#2f6fd6',            // 学科色：卡片、图标底色
  editions: [ … ],             // 不变
  resources: [
    { group: 'practice', icon: '词', title: '英语单词', desc: '每天 10 分钟背课本单词', href: '#/words' },
    { group: 'practice', icon: '题', title: '英语试题库', desc: '按知识点和题型练错题', href: '#/english-bank' },
    { group: 'notes', icon: 'Aa', title: '英语学习大纲', desc: '上海初中英语知识点梳理', href: 'content/english/shanghai-junior-outline.html' },
    { group: 'exam', icon: '真', title: '中考真题', desc: '上海历年原题，另有江苏', href: '#/english-exams', stage: 'zhongkao' },
    …
  ],
},
{ id: 'chinese', name: '语文', color: '#c0513a', editions: [], resources: [ … ] },
```

字段：

| 字段 | 说明 |
|---|---|
| `group` | `practice` 练习 / `notes` 资料 / `exam` 考试 / `games` 玩法 |
| `icon`、`title`、`desc`、`href` | 同现在的列表行 |
| `stage: 'zhongkao'` | 中考类资料，按年级折叠，见下文 |
| `from: '<学期ID>'` | 从哪个学期起适用（游戏用；资料也可以用） |
| `special` | 需要页面代码接管的入口：`'exam'`（小节测试，没登录先登录）、`'mock'`（模拟考试，有这一科的卷子或可解锁时才出现）、`'textbook'`（课本资料，口令解锁）。`mock`、`textbook` 渲染时先放一个占位元素，由 `MockExam.entryRow`、`PrivateUI.homeLinks` 换成真正的行（不出现就删掉占位），文字也由这两个模块决定，数据里的 `title`/`desc` 只是说明；`exam` 用数据里的文字 |

游戏是跨学科的，单独放在目录顶层 `Content.catalog.games`（字段同现在的 `FUN_GAMES`，加 `from`）；数学的 `resources` 不重复列出，数学学科页按 `subject: 'math'` 取。

`content.js` 加两个查询函数：`Content.subjects()`（含没有课本的学科）和 `Content.resources(subjectId, semesterId)`（按年级过滤后的条目，带上折叠标记）。

目录文件头上的注释、`content/AGENTS.md` 的目录格式、`docs/templates/subject-AGENTS.md`（加学科的步骤）同步写明 `resources` 的用法：**以后加学科或加资料入口，只改 `catalog.js`，不改首页代码。**

## 按年级显示

当前学期取右上角选的学期（现有的 `xq.grade.v1`），年级是学期 ID 里的数字（`g6s1` → 6）。

- **中考专区**：`stage: 'zhongkao'` 的条目在六～八年级收进学科页最下面的一行“中考专区（n）›”，点开就地展开；九年级不折叠，按 `group` 正常排在各组里。首页不出现中考类入口
- **游戏**：按 `from` 过滤，见上文
- **其他册**：学科页的“其他册”列出全部，不按年级藏，方便往前复习

折叠只是显示上的，路由都能直接打开，不做权限限制。

## 样式

首页和学科页一共只用三种组件：

1. **列表行**（`note-row`）：今天、学科页各组。图标底色用学科色
2. **学科卡片**：只在首页，两列
3. **游戏宫格**：首页趣味玩法、数学学科页、`#/games`

现在的两列小格（`home-tile`）、学科小块（`home-chips`）不再使用，样式删掉。课本卡片（`card volume`）只在学科页用。

## 改名

界面上的“试卷”改为“小节测试”：首页（现在的练习区）、`#/exam` 页标题、结果页里出现的地方。路由、存储键（`xq.exam.v1`、`xq.history.v1.<账号>`）不变。“模拟考试”“中考真题”保持原名。

## 路由与存储

| 新增 | 说明 |
|---|---|
| `#/subject/<学科ID>` | 学科页；学科 ID 不存在时回首页 |
| `#/games` | 全部趣味玩法 |
| `xq.lastVisit.v1.<归属>` | 上次打开的小节 `{ section, at }`，经 `LearningStore` 按账号隔离 |

登记在 `docs/storage-and-routes.md`，同时改写那里 `#/` 首页的描述。

## 分步实施

每步单独提交、单独审核，`node tests/run.js` 全绿。

1. **学科登记**：`catalog.js` 加 `resources`、`games`、语文物理化学三个学科条目和学科色；`content.js` 加查询函数；`home()` 改为从登记读数据，**页面外观先不变**。测试检查每个条目字段齐全、`href` 指向存在的文件或已知路由、`special` 取值合法
2. **学科页**：新增 `#/subject/<学科ID>`，几个下一层页面的返回键改回学科页。首页暂时不动，只在各区标题旁加临时入口供走查
3. **首页改版**：今天块（含 `xq.lastVisit.v1`）、学科卡片、趣味玩法过滤和 `#/games`；“试卷”改名；删掉不用的样式。`tests/home-subjects.test.js` 现在是截取 `home()` 源码查字符串，这一步按新结构重写
4. **按年级显示**：中考专区折叠、游戏 `from` 过滤；按六年级、九年级各走查一遍

第 3 步要在手机上实际看一遍（无头 Chrome 跑不完动画，但静态布局可以截图），320px 和 375px 两个宽度。
