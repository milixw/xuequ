# 七天复习提交记录重做

每条有错题的提交记录旁增加“重做”，结果页也有“重做本次错题”。零错题记录显示“无错题可重做”。重做范围仅为该时间点保存的错题，不重做当天全部题，不修改旧记录。新路由 `#/english-plan/<天数>/retry/<记录ID>`。

从原记录题干及参考答案快照还原独立题单（单选、完形、阅读复合选择），即使题库内容后来调整，也不改原题或判分依据。首次进入不带上次选择；选择存入独立 `xq.english-plan-retry.v1`：`{ drafts: { [源记录ID]: 作答 }, submissions: { [新记录ID]: { sourceId, review: [题目与作答快照] } } }`。不改变每日草稿，也不改旧键结构。离开后可继续；提交成功清空该重做草稿，下轮重新开始。

沿用每日题单的渲染和判分，至少完整回答一道题才可提交。提交产生新的唯一时间点，按原有格式追加到 `xq.english-plan-prints.v1`（包括全部答对）；不会覆盖每日最近结果。新记录中的错题可继续重做。结果页显示本次重做的错题、已答对题的选择、参考答案与解析，未答题不算错题；打印只保留仍错的原题。用新记录 ID 去重写入进度和累计错误次数，刷新不重复计数。

校验：旧快照题干和答案不变；单选、完形、阅读可以作答；草稿独立及刷新恢复；旧入口和零错题保留；未答不产生记录；多次快速提交 ID 不冲突；重复提交事件不累计；存储失败提示；结果与打印不提前泄露答案。
