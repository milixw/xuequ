# 上海语文与数学中考原题

本次只收录上海，不扩展江苏。首页增加数学、语文中考入口，按年份组织，原有教材、英语入口不变。首批从用户本地 2023—2025 年 PDF 整理，保留文件自身的题号（语文资料将整组阅读重新编号，不冒充官方小题号）。不是完整历年或整卷导入。

## 内容

数据通过 script 加载 `content/past-papers/shanghai.js`，全局 `ShanghaiSubjectPapers`。`papers` 中每份包含 `id`、`subject`、`year`、`title`、`version`、`source`（相对路径、SHA-256）、`questions`、`skipped`、`review: pending`。题目 ID `sh-<学科>-<年份>-q<资料题号>` 固定不变。题干与选项保留原资料内容；数学符号转成等义 KaTeX，文字上标保留；图或公式不完整的题先跳过，不补造。

语文按原资料整道阅读题保留全文与所有小问，`type: written`，用文本框作答并查看整题参考答案。作文若存在原文范文，仅视为参考、不作标准答案判分；首批不导入作文以避免误用。PDF 下划线、加点和波浪线位置必须人工核对，无法恢复时跳过依赖该标记的整题。

数学首批选择题 `type: choice` 四个选项，明确原答案时自动判分；填空/解答 `written`，展示作答与参考解析，不自动判对错。数学题干采用经过原 PDF 页面核对的文字转录，答案与原解析从同一个文件按题号补入；无法提取完整数学解析时标待核对，不冒充完整解析。

## 页面及进度

`#/shanghai-papers/math`、`#/shanghai-papers/chinese` 为年份目录，后接 `/<年份>` 为试题页。地区固定上海；未知学科/年份显示错误。各科独立首页入口，不把语文挂到英语区。

新模块 `src/subject-papers.js`，文字安全转义，数学通过本地 KaTeX 渲染，长文与数学式可横向滚动，移动端文本框和按钮最小 36px。答案默认隐藏，作答后或查看答案显示。

`xq.subject-papers.v1.<归属>` 由 LearningStore 按账号/访客隔离，结构 `{ [试卷ID]: { [题目ID]: { response, attempts, wrongCount, revealed, solved } } }`。只对有明确答案的选择题累计错误；主观题不标答对、不计错。账号切换时旧表单拒绝写入，存储失败明确提醒；不改数学原有共享进度或英语记录，不迁移旧数据。

首批数学 38 题、语文 13 道整组题，全部有参考答案。数学原解析仅展示无公式及几何标记的可靠文字，压平的数学表达式不展示。语文跨题材料存入 `context` 与 `contextLabel`，默认展开，题型筛选后也可独立作答。

## 验证

检查源文件哈希、稳定题号、图/公式/批注残留、数学 KaTeX 语法、选择题答案格式、语文阅读完整性、科目/年份路由、答案隐藏、空作答拒绝提交、选择题判分、主观题不误判、刷新恢复与账号隔离。全量 node 测试通过后交付，不自动提交或推送。
