# 上海英语原题补全

按本地原卷补回漏导题型，优先正文文本；承载信息而无法可靠转录的图保留局部原图。保留已发布题目及 ID，不重导覆盖人工订正。2019 整理版笔试重新编号，听力使用独立 ID 前缀，避免与笔试重复。

新增选词、首字母、句型转换、简答、作文和可核对听力题。相同材料合并展示；自由简答和作文只显示参考答案供核对，不按字符串不匹配自动计错。缺音频的听力保留题目并说明，不用机器朗读冒充原录音；原听力文字在订正区折叠。图片在题干和答案区分别展示，提供独立放大链接。

定向补充脚本先校验来源 SHA-256；新增内容 pending。转录记录保存正文、来源哈希和必要图片元数据。原资料缺失、损坏及回忆版冲突逐项记录，不能用答案编造题干，不能以“已收录”冒充官方完整卷。

验证：原 ID / 已有答案不变、每年题号覆盖与明确缺口、文本不混入答案或水印、图片文件与来源绑定、主观题不会误计错、账号隔离及离线加载，全套 JS 校验及导入回归。
