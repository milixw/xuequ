# 上海原题混合展示

用户同意对之前未添加的上海原题改用文字与本地截图混合展示。优先保持已发布文字题、ID、答案和进度不变；仅追加缺题。PDF 按原题号定位整个题目，跨页存多张按页序的截图，保留原图、选项与全部小问。答案区独立裁图，不得出现在题干图片里。不裁掉公式和图表，不从答案反推题干。

新增可选字段 `stemImages`、`answerImages`：数组元素 `{ src, page, bbox, width, height }`，src 限 `content/past-papers/images/<试卷ID>/...png`，page 为一基页号，bbox 为源 PDF 的点坐标。图片保存在项目内，使用 img 本地加载、异步解码、宽度自适应（不延迟加载，保证长题单打印完整），点击原图可放大，打印保留题图及文字选项、隐藏答案区和作答控件。原图片化单选题使用 `optionsInImage: true`、A—D 选择控件；仅明确核对原答案字母才自动判分，其余保存作答并人工订正。

导入脚本验证原来源 SHA-256、独立参考答案边界、题号唯一连续、源/答案题号对应后，生成本地 PNG 和清单。图片题使用稳定原 ID；不替换旧文字题或人工修改。原解析在答案图中时明确标注，未恢复的题继续列待转录。第一批处理已有上海语数物化目录中有独立答案区且题号可定位的 PDF；扫描件、只有 Word 的版本以及英语独立题库仍待后续逐份核对，不宣称全部补齐。全体 review.status=pending。

验证题图不跨答案边界、跨页排序、图片路径安全、不覆盖旧题、单选判分、主观题不误判、账号隔离、答案默认隐藏、打印隔离和原图抽查。文件直开可用，不用 fetch、CDN 或 Word/PDF 链接代替题目。
