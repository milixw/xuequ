# 立体图形实验室

日期：2026-09-23

## 目标

在首页"趣味玩法"里加一个独立页面，用可旋转、可折叠的 3D 图形帮学生理解立体图形：展开图、侧面展开、表面最短路径、截面。不限年级，分章按主题组织。

现有教材资料（`docs/textbooks/` 里的六上、七上、七下、八上、八下）都没有立体图形内容，所以这里的"章"是本模块自己的主题分章，暂不挂课本章节；等补齐六下、九年级资料后再对应。

## 交互

- 画布上拖动旋转视角，"重置视角"按钮恢复
- 折叠类统一用一个滑块，左端"展开"、右端"立体"，旁边的播放按钮做动画
- 数值用滑块加 −/+ 按钮调节，数值实时显示
- 移动端优先，320px 宽可用，按钮不小于 36px

## 技术

- 不引入 three.js。自己写 Canvas 2D 投影（透视 + 画家算法按深度排序），足够画多边形拼成的立体
- `src/games/solids/geo3d.js`：纯几何，不依赖 DOM，导出给测试
  - 正方体展开图：展开图存成面的树，每个面绕它和父面的公共边旋转 $t\times90°$，从叶子往根逐层叠加；六格图形穷举得到 35 种，能折成正方体（6 个面位置互不相同）的正好 11 种
  - 圆柱：侧面截面是一段弧长固定为 $2\pi r$ 的圆弧，曲率从 $1/r$ 渐变到 0；上下底面绕切线翻开
  - 圆锥：母线长和扇形圆心角固定，把扇形贴在底面半径 $\rho$ 从 $r$ 变到 $l$ 的一串圆锥上，$\rho=l$ 时就是平面；中间那条母线始终不动，底面绕它的端点翻开
  - 长方体最短路：三种走法各取两个面，第二个面绕公共棱转到和第一个面共面
  - 截面：平面和 12 条棱求交点，按角度排序；按边长、角度、平行关系判断形状名称
- `src/games/solids/game.js` + `index.html`：页面、控件和渲染；关卡用页内 hash，比如 `#2-2`
- 本地存储 `xq.solids.v1`：`{ done: [关卡ID], nets: [已拼出的展开图标准形] }`
- `tests/solids.test.js`：11 种展开图、折叠后闭合、相对面、题目数据可解、圆锥扇形、最短路径和公式一致、截面形状在滑块取值下都能切出来
