# 按账号隔离七天复习与错误次数

七天每日草稿、提交记录、重做草稿及订正结果、累计错误次数按账号保存；英语题库练习进度也按账号隔离，避免 A 的完成状态影响 B。数学教材练习进度继续使用原共享键，不扩展本次范围。

共用 `LearningStore` 决定存储归属。键后缀为 `.user:<encodeURIComponent(账号)>`，未登录为 `.guest`，二者永不互相回退。七天、打印、重做、错误统计升级为 v2；英语进度独立为 `xq.english-progress.v1`。旧全局键只读保留，首次迁移复制到 `.legacy` 备份区域，不作为访客数据读取。

切换账号或退出时，同页缓存重新加载；已打开的旧表单在检测到账号变化后拒绝作答和提交，防止跨标签页把记录写给另一人。新账号无草稿、无提交记录、无错误次数；同一题或同一提交 ID 在不同账号中各自统计。

用户明确指定旧共享记录归入“我是臭恩铭”。首次加载自动向该账号合并旧数据，迁移完整成功后保存 `xq.learning-migration.v1` 标记；保留旧键和 legacy 副本，不再给其他账号自动导入。不覆盖目标已有题干或选择；提交 ID 冲突时给导入记录新 ID，并同步重做关联和错误事件。累计计数、练习次数取较大值，完成/解析标记取并集，避免重试翻倍。计划页面标明当前归属。所有存储读写有异常保护；写失败保留原数据，下一次加载重试。

测试覆盖中文/特殊账号名编码、访客隔离、同页账号切换、旧表单拒绝写入、旧共享数据迁移与重复导入、存储失败、历史重做/打印不回退至他人记录。
