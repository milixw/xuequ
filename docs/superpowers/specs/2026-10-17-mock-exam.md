# 模拟考试：私有库里的整卷试卷与解析

2026-10-17 与维护者讨论确定。

## 背景与目标

维护者收集了一批整卷资料（学校期中卷、模拟卷，带完整解析，PDF 或 Word），想让学生**按整卷限时模拟考试，交卷后看完整解析**。

和现有的“真题卷”（`content/exams/`）不一样：真题卷是把原题拆开、按课本小节归类，解析用自己的话重写，可以进开源库；这里是**原样整卷使用**，有版权风险，所以放私有库 `xuequ-private`，沿用课本资料的口令服务和分享链接授权。

这一版只做：计时作答（学生在纸上写）→ 交卷后看解析 → 自己填一个分数。**不做在线逐题判分。**

## 第一批资料

原件在 `refs/六年级期中/`（不入任何仓库），按“年级 + 期中/期末”分卷集，第一个卷集是 `g6s1-mid`（六年级上学期期中）：

|---|---|---|---|

| `math-fenghua-2025` | 数学 | 2025-2026 静安区风华中学（16 页） | 第 1～4 页试卷，第 5～16 页解析 |

## 总体结构

```
私有仓库 private/
  exams/<卷集ID>/<卷ID>/paper/p001.jpg …    试卷页
  exams/<卷集ID>/<卷ID>/answer/p001.jpg …   解析页
  exams/<卷集ID>/review/p001.jpg …          复习资料页（卷集里可以没有）
  texts/exams-<卷集ID>.json                 人工维护：每份卷的原件路径、拆页范围、要遮掉的区域、时长、满分
  scripts/build-exams.py                    读 refs/ 和上面的 JSON，生成页面图片，并写 manifest.js 的 exams 一节
  manifest.js                               现有的 english 一节之外，加 exams 一节

开源仓库
  src/private-ui.js 或新文件 src/mock-exam.js  首页入口、#/mock 页面
  scripts/private-gate.js                     分享链接打开后跳转的页面按范围决定（见“授权”）
```

### manifest 的 exams 一节

```js
Private.manifest({
  english: { … },              // 现有，build-english.py 生成
  exams: {
    'g6s1-mid': {
      title: '六年级上学期期中',
      review: { title: '期中复习宝典', note: '…', pages: 16, size: [1239, 1754] },
      papers: [
        { id: 'math-lida-2025', subject: 'math', title: '黄浦区立达中学（2025 学年）',
          minutes: 90, full: 100, paper: 5, answer: 13, size: [1240, 1754] },
        // paper、answer 是两部分的页数，size 是页面图片尺寸；可选 maxScore（自评分数上限，默认 full）、note（开始前的说明）
      ],
    },
  },
});
```

- 两个生成脚本写同一个 `manifest.js`：都是读回已有的、只替换自己那一节（`build-english.py` 原本就这样写，不用抽公共函数）。
- 页面图片沿用课本的做法：宽约 1240，JPEG 质量 55，文件名三位页码；一份卷大约 1～3MB。
- 渲染 PDF 用现有的方式（pypdf 拆页 + qlmanage 渲染 + sips 压缩）；Word 用 Pages 导出成同名 PDF 放在原件旁边。

## 授权

口令服务现在的规则是：`private/<类别>/<ID>/…` 对应授权项 `<类别>:<ID>`。所以 `private/exams/g6s1-mid/…` 自然对应 `exams:g6s1-mid`，**放行规则不用改**：

- 只给模拟卷：`./scripts/share-link.sh exams:g6s1-mid`
- 课本加模拟卷：`./scripts/share-link.sh english:g6s1,exams:g6s1-mid`
- 全部资料的链接和口令照旧，也能看模拟卷

要改的小地方：

1. `private-gate.js` 的 `list`、`share` 本来就按 manifest 的“类别:ID”通用处理，exams 下的卷集自动列出、能校验，不用改。
2. 分享链接打开后现在固定跳到 `#/textbook`；改成范围里**只有** `exams:` 时跳到 `#/mock`，其余照旧。
3. 页面的 `pruneManifest` 已经按“类别:ID”过滤，exams 一节自然适用。只有模拟卷权限的人，课本那一节会被过滤空，这时首页**不显示**“🔑 课本资料”。
4. `setup-server.sh` 的 rsync 白名单加上 `exams/`，上线检查加一条：拿凭证请求一张试卷图片，应该返回 200。

## 页面

**入口**：首页“练习”区加一个“模拟考试”小格（原打算放“复习资料”区，但那里按学科分组，模拟考试跨学科，又是做题，放“练习”更合适）。规则和“🔑 课本资料”一样：本机有私有资料就直接用；线上没解锁时点它弹出口令框；没有口令服务时不显示；已解锁但范围里没有卷集时也不显示。本机开发服务器 `scripts/serve.js` 的私有文件白名单加 `exams/`。

**路由**（登记到 `docs/storage-and-routes.md`）：

| 路由 | 内容 |
|---|---|
| `#/mock` | 能看的卷集列表；只有一个卷集时直接进去 |
| `#/mock/<卷集ID>` | 卷集里的卷子按学科分组，每份卷显示时长、满分、做过的话显示自评分数；有复习资料的话放在最上面 |
| `#/mock/<卷集ID>/<卷ID>` | 一份卷子（见下） |
| `#/mock/<卷集ID>/review` | 复习资料，竖排翻页 |

**一份卷子**（翻页查看和课本资料一样：页面图片竖排，滑到附近才加载，双指放大用浏览器自带的）：

1. **开始前**：卷名、时长、满分、“请准备好草稿纸和笔，在纸上作答”，再放一个“开始考试”按钮。
2. **作答中**：试卷页竖排；顶部固定倒计时条，加“交卷”按钮（点了要确认一次）。最后 5 分钟倒计时变成橙色。时间到自动交卷。中途关掉页面再打开，按开始时间接着计时（存在本机）。
3. **交卷后**：显示用时；解析页出现在试卷页后面，加一个“只看解析 / 试卷和解析都看”切换；底部可以填自评分数（0～满分），保存。
4. **复做**：“重新做一遍”清掉这份卷的计时，自评分数留下来，作为历史记录。

解析页的图片在交卷前不放进页面。这只是防止学生顺手翻到，不是保密措施，因为知道地址的人也能直接打开图片。

**新存储键**：`xq.mockExam.v1`（localStorage，不分账号）：

```js
{ "g6s1-mid/math-lida-2025": {
    "startedAt": 1760000000000,      // 进行中才有
    "history": [{ "at": 1760005000000, "usedSec": 5100, "score": 86 }]   // 每次交卷一条，最多留 10 条；score 填了才有
} }
```

读写都包在 try/catch 里；读不到就当没做过。

## 开源仓库的防泄露

- 开源库只放查看器代码；卷名、学校名、页数都在私有库的 manifest 里，开源代码和文档里不写具体卷子
- 现有测试（git 不能跟踪 `private/` 下的文件、开源代码里不能出现口令）照旧
