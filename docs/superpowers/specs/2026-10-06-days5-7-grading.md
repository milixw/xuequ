# 第 5～7 天自动作答与核对

阅读复合选择题按原文件全部小题答案补齐，原版本只保存第一答案不再作为整组答案。保留题目 ID、正文、原解析和来源。缺原答案时先核对同篇同选项的本地版本；确无原答案的客观题使用单独标注的 AI 待审核补充。

词语填空、首字母、词形、句型转换使用按稳定 ID 登记的原资料答案列表，每空输入；匹配选项题允许逐空选择字母。保留整题统计，全部填完才提交判分。题目数据的补充元数据位于独立 grading-supplements.js，不改变存储键和快照格式。

阅读简答和翻译题提供输入、参考答案匹配。仅大小写、空白、标点和常见缩写规范化后匹配成功时自动确认；不同合理表述不直接计错，列为需人工核对，并在结果页展示原作答及参考答案。错题重做保留原答案快照，不能用当前答案覆盖旧快照。

判分补充均 pending，原资料答案注明来源；所有新解析区别标 AI，不冒充原解析。原提交不重新判分。
