# 首页五学科入口与学习大纲

> 2026-09-28 更新：此设计已由用户撤回。当前首页恢复为教材、独立试卷、趣味玩法布局；仅额外保留英语学习大纲与英语试题库两个入口。下文保留作历史设计记录，以实际代码和 `AGENTS.md` 为准。

首页先显示「各科学习大纲」，再显示「选择年级与学期」，最后按「数学、语文、英语、物理、化学」显示五张该学期教材卡片。大纲是跨年级的可展开概览：数学从现有 `content/catalog.js` 中提取每册章节；英语按用户提供的《上海初中英语知识点系统梳理》整理，并将完整 HTML 保存于 `content/english/shanghai-junior-outline.html` 供离线阅读；语文、物理、化学暂无教材原件，仅展示标明「待提供教材核对」的规划提纲，不冒充正式教材目录。目录中已有对应册时，卡片内直接列出教材链接；暂无对应册时清楚标记「教材待添加」，不虚构教材。切换学期后，下面五张卡片同步更新。

英语当前暂无 catalog 教材，卡片保留独立错题库 `#/english-bank` 链接；数学卡片链接对应学期教材。语文、物理、化学入口使用 `#/subject/<学科ID>` 显示明确的「该学期教材暂未上线」说明，不创建空目录或死链接。后续有真实教材内容时，可在 catalog 中登记，再由首页和学科页自动列出。

首页采用两列卡片，窄屏改为单列；学期切换器位于教材卡片上方，保留趣味玩法。英语题库继续用本地 `<script>` 资源加载，直接打开 `index.html` 时可用。测试覆盖五个入口、学期过滤、路由和英语脚本的依赖顺序。

试卷不再作为首页独立卡片。每个学科卡片在有已上线小节的对应教材时，显示指向该册的「试卷 · 按章节限时测试」入口；暂无可考内容时显示「试卷待上线」。点击可用试卷时仍按现有流程要求登录。
