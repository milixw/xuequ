# 英语错题试题库

## 目标与边界

首页增加独立的「英语试题库」入口，不依赖数学教材册或账号。将用户提供的 `D:\下载\新东方英语\错题` 中 PDF 的题块按原文导入，并按选择题、完形填空、阅读理解、填空题、补全题、主观题分类。保留源文件名、原题号、PDF 页码以便人工复核；不改写题干。

## 数据与隐私

`scripts/import-english-bank.py` 用 pdfplumber 读取本地 PDF，按题型和题号标记切分，提取参考答案，对完全相同的题干去重并汇总来源。导出 `content/english/question-bank.js`，通过 `<script>` 按需加载，保证直接打开 `index.html` 可用。题目 ID 是归一化题干的哈希；若人工修改题干，需评估进度关联。每条记录有 `id/type/text/answer/sources/review`，其中 `review` 固定 `pending`。

原始 PDF 含学生标识，不能放进代码库。导入时剔除页眉、页脚和学生编号，脚本在写入前扫描常见标识；测试再次核查。不要把本地源目录的清单 CSV、PDF 或截图提交。

## 页面

首页 `#/english-bank` 显示题型筛选、全文搜索、题量和分页式加载；`#/english-bank/<题目ID>` 显示原题、来源和 PDF 参考答案。答案为单个 A-D 且选项能识别的选择题可自动判分；完形填空按原题题号拆出各空选择框，全部作答后给出答对空数。PDF 提取可能丢失正文空格线，不猜测其位置或改写原文；其它题型只展示参考答案。所有题目均提示「机器提取、待人工核对」，因为图片、下划线、排版和答案识别可能不完整。答题和查看答案状态沿用 `xq.progress.v2`，逻辑分组 ID 为 `english-bank`，与数学题进度隔离。

题目页的「重置本题」在已有记录时先确认，然后清空完形填空当前选择、反馈，以及这道题在 `xq.progress.v2` 中的尝试、完成、查看答案记录；同组其它题不受影响。

知识点学习顺序：`content/english/knowledge.js` 为每个知识点提供通俗说明、例子和 `review.status: pending`，并按题干、选项与题型为每道错题自动分配一个主要知识点。列表与题目页均先显示该知识点介绍，再显示原题；列表可按知识点、题型和关键词筛选。难以可靠判断的题归入「综合语法与词汇（待细分）」，不修改题库原文或题目 ID。归属只作学习导航，正式统计掌握程度前需人工复核。

## 验证

`node tests/run.js` 校验题库数量、题型、字段、来源、隐私清理和筛选函数。界面需在 `file://` 和 320px 手机宽度下可操作。正式作为教学内容使用前，还需逐题对照原 PDF 人工审核，尤其是带图和综合题。
