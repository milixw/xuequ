# 上海英语历年真题网上交叉补录

按公开可阅读的原卷整理资料交叉核对，优先补入2021—2023年，并核查2024—2025年可取得的原文。网页标题不能证明年份；以题干、题号、听力版本和原答案共同确认。

保留当前715个作答项逐字不变，新题使用sh<年份>-q<原题号>，整理版重新编号须显式记录与原卷的对应关系。来源记录网址、下载内容SHA-256、核对日期、差异与未补缺口；新增题目pending。主观题人工核对，争议答案不自动判分。必要原题图片本地保存，使用现有离线script加载，不新增存储或路由。

补录采用独立来源清单和幂等定向脚本；先验证所有记录和重复ID，再一次性更新目录，已有题目发生差异时拒绝覆盖。页面展示实际覆盖情况，缓存版本随数据变动。

验证：旧题对象哈希不变、每年题号覆盖、选项与答案映射、原文不混入答案解析、必要图片哈希、主观题评分、缺口说明、全套JS与定向导入回归。

2021、2022整理版笔试1—64映射原卷21—84；2023采用原号。听力选图局部原图3张，2021动物园阅读材料原图1张。2023主预览遗漏StreetFun全文和第60题选项，由第二份公开原卷补核；少量断词、空白和下划线按相同原文恢复。多空句型转换统一人工核对，避免参考写法差异误记错误。

2021第49题多个整理来源将参考答案写为service，保留来源答案并说明疑义，人工核对；不推测替换。2022第47题多个答案表一致为used，保留来源写法。2023作文来源写“略”，记录null，不把此字当作答案。

2024中考网的三页“试卷”实际是听力文字，缺原选择项与完整笔试，不能由答案表还原原题；本批只录第6—10题原问题，保留听力文字于订正区，答案null。公开作文回忆主题可互证，但本批未获得带原题号的原卷，暂不臆造编号。2025可取得资料与本地听力资料重复，部分所谓2025卷出现2018世界杯等旧题，排除；作文回忆可与考试院点评互证主题，但不足以还原完整卷。2026保持原回忆题和缺口，本批没有补推测题。上述年份仍有未解决缺口，不能称为历年全卷已补齐。

## 浏览器验证

真实Chrome的file://加载发现原渲染器在严格模式给textarea.type只读属性赋值，遇到主观题会中断整页。仅对input设置type修复；测试DOM同步模拟只读属性，避免模拟器掩盖此类错误。2021—2024页面在320px宽下逐页检查：2021—2023各53组、84作答项，2024为5组；无脚本错误、无坏图、无横向溢出。原录音缺失不以机器朗读替代。
