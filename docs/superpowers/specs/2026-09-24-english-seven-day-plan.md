# 英语错题七天复习计划

英语错题库列表顶部增加 `#/english-plan` 入口。计划概览把 `EnglishKnowledge.classify` 的每个知识点固定分配到七天中的一天，实时从题库统计原题数和有参考答案的题数；每题只出现一次，不改变题干、答案、ID 或现有做题进度。每天设置建议练习量，明确这是一轮重点复习，不要求七天刷完全部 460 道题。

`#/english-plan/<天数>` 显示当日全部原题，仍可沿用原有 `#/english-bank/<题目ID>` 做题页。第七天混合复测并回顾前六天仍不会的题；分类和 PDF 机器提取答案仍需人工核对，无答案题不计入正确率。

每日题卡直接保留原题文本里的换行，使题干与 A、B、C、D 选项逐行显示；不把换行合并为空格，也不截断原题。正确答案仍在做题页由学生主动点击查看，避免在练习列表提前泄露。

每日练习升级为整天完整题单，去掉“显示更多”。可识别的单选题在题单内直接点选 A—D，不加“选择一个答案”外框；可完整解析的完形填空按空选择，有完整逐题答案的阅读题可逐小题选择。每次选择立即保存为本地草稿（`xq.english-plan.v1`），重新打开当天可继续。提交只对有可靠参考答案且已完整作答的题判分；未答题和机器提取不完整、无法自动判分的题单独提示，不算错题。提交时对已判分题写入现有 `english-bank` 进度分组，然后导航到 `#/english-plan/<天数>/result`，只列本次答错的原题，并在每题后显示本次选择和 PDF 参考答案。结果是本次提交的快照；再次提交会更新快照，题目 ID 和原始内容不变。所有本地存储读写都捕获异常。

每个知识点都先展示通俗讲解、至少三步可执行的判断方法、例子和至少三条带“错误—改法—原因”的易错提醒，然后才列出该组原题。七天计划的每日题目页、错题库分类页、单题页复用同一份 `knowledge.js` 数据和讲解组件，内容保持待人工审核。自动分类优先看选项差异，避免题干里的背景词把明显的连词、非谓语等题目误分；仍不把自动分类当作教师审核结论。

连词知识点额外展示九组、44 项的复习清单，覆盖并列连词、成对连接结构、时间、条件、原因、让步、目的与结果、比较与地点、宾语从句连接词；每项写用途与独立例句。清单根据用户提供的上海初中英语梳理 HTML 整理。上海市教育考试院的公开评价指南将连词分为并列与从属两类，但未把这里的 44 项列为统一逐词必背表，因此页面明确标成复习清单，并对较正式或较少用的项目标注“了解”。

清单后另有 `confusables` 易混辨析，逐组对比 when / while / as、because / since / as、if / whether、unless / if ... not、让步连词、原因与结果连接词、so ... that / such ... that / so that、until / not ... until、as soon as / when / after、in case / if / as long as 及成对连接结构。每组给判断规则、至少两个不与原题撞车的例句和易错提醒；七天计划与错题页共用这一讲解。

其余 14 个知识点也各有至少三组 `confusables`：语法类对比形式和用法，阅读、完形、填空、对话、写作类对比容易混用的判断策略。每组包含区别说明、两个以上独立例句和一条具体易错提醒；综合待细分类强调自动标签与 PDF 提取不确定性，不能冒充正式语法专题。

七天计划概览在第一天卡片之前放置展开的「先学：连词与状语从句」，复用完整知识点讲解、清单和易错提醒。浏览器 A4 打印时隐藏这段较长的课前讲解，只打印紧凑的七天日程；第一天的每日原题页仍先讲再练。

概览页提供浏览器打印按钮，打印样式使用 A4、12 mm 页边距，隐藏导航与操作按钮，并避免单日卡片跨页；纸面保留每天的学习重点、自检要求、勾选和复测填写位置。直接打开 `index.html` 仍可用，不通过 `fetch` 读取本地文件。
