# 每题累计答错次数

增加独立的 `xq.errors.v1`：`{ counts: { [分组ID]: { [题目ID]: 次数 } }, events: { [提交事件ID]: true } }`。继续使用原来的进度键，不改变原结构。

`Progress.record` 对一次已判分的错答加一，正确、未答、无法判分不加。英语七天计划给每题传入由提交记录 ID 和题目 ID 组成的事件 ID，避免同一提交重复统计。完形或多小题阅读按整道原题统计，任一空错则该次整题记一次。

首次读取时，从已保存的错题打印记录和最新七天结果导入明确的错答事件，按事件 ID 去重；之后的新提交使用相同 ID 规则，刷新或打印不会重复计数。旧版只有尝试总数，无法准确还原历史错答，不据此推算。

英语题库列表、单题作答页和七天错题页显示累计次数。重置本题只清除原有练习进度，保留累计错误次数和历史提交。打印隐藏错误次数，继续只显示原题。
