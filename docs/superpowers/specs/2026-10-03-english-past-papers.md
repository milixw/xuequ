# 上海英语中考文字题

## 目标与来源

首页英语区及英语试题库增加“英语中考真题”入口，按年份倒序排列。用户补充要求读取原文件内容生成网页题目，不用图片或 Word 下载代替题目。题干、数据、选项、原资料题号与已有解析不改写，不凭答案补造缺失真题。

检索 `F:\BaiduNetdiskDownload` 与 `D:\下载\中考真题` 后，找到 2013—2020 年整理卷、2025 年听力与参考答案、2026 年非官方回忆版。没有找到 2021—2024 年上海英语试卷。重复资料 SHA-256 一致，只提取一次。

## 导入结果与限制

最终校验后共 253 道文字题：2013 年 34、2014 年 34、2015 年 34、2016 年 17、2017 年 25、2018 年 35、2019 年 27、2020 年 39、2026 年 8。初次有 216 道原资料答案；后补 2017 年原答案表两题及 2018 年公开资料核对的 35 题，目前 253 道均有参考答案，其中 35 道不是本地原文件答案，须在页面明确区分。题型为语法与词汇选择、词性转换、可提取完整文章的阅读理解和完形填空。初步提取的 263 题中，10 题因图片依赖或正文不完整在最终校验时剔除。所有导入编排保持 pending，仍需教师逐题核对。

这不是整卷导入。听力题、依赖图片的阅读或选项、无法可靠提取的下划线、题干缺失、答案冲突的部分先跳过。部分旧资料本身是 OCR 整理文本，保留它的原拼写，并标待核对，不私自改成推测的原题。2019 年整理文件自行使用 1 起的题号，保留所给资料编号，不冒充已核实的官方卷编号。

2025 年名为“真题+答案”的压缩包实际只有听力原文、速记和答案图片，没有完整笔试题干；页面显示待补充，不伪造题目。2026 年 PDF 明确说明是非官方回忆版，存在缺失和冲突；只从中提取可辨认的 8 道词性转换题，原答案待核。2025/2026 年媒体保留为听力入口，尚未导入听力题，也未逐题核对音频对应关系。

## 内容与实现

- `content/english/past-papers/catalog.js` 用 script 离线加载，`papers` 含年份、版本、缺失提示、来源相对路径及源文件 SHA-256、`questions` 与 `skipped`。原件不作为页面运行链接。
- 题目字段为 `id: sh<年份>-q<原资料题号>`、`originalNo`、`type`（choice/fill）、`category`、`stem`、可选 `passage`、`options`、`answer`、`explanation`、`review.status`。保留已发布 ID。
- `scripts/import-english-past-papers.py` 读取 PDF 和 DOCX，旧 DOC 的主文字流由 `scripts/word-binary-text.py` 从 Word piece table 读取。缺选项不猜；不完整或依赖图片的文章不导入。字体私用撇号仅恢复可见英文撇号。DOCX 源下划线用 `[[u]]...[[/u]]` 保留。
- 再次导入保留已有题目及人工订正，只追加新 ID；已发布年份源文件 SHA-256 改变时拒绝覆盖，要求人工核对，避免更换原题或把不同版本答案混入。
- 补答案模式 `--supplement-answers` 先验证原文件 SHA-256，仅填已有题目的空答案，不改题干、选项、解析、ID、审核状态与已有答案。2018 年补充表在 `answer-supplements.json`，每题增加 `answerSource` 保存公开来源网址、日期及 pending 状态，界面标“补充参考答案（公开资料核对·待审核）”；不冒充官方答案。重复执行不再写入新答案。核对笔记见 `docs/references/2018-shanghai-english-answer-check.md`。
- `src/english-exams.js` 只解释下划线标记，其他内容按纯文本显示。原题分行、ABCD 紧凑排列；同类别、同一完整文章的阅读/完形小题合为一道大题，文章仅显示一次，全部小题置于同一表单统一提交；漏答时整题不写进度，提交后逐小题显示答案、解析并按原 ID 记录进度和错误次数。数据仍保留已发布小题 ID 和文本，不改存储结构。列表分别显示大题数和作答项数，可按题型筛选。
- `#/english-exams` 年份列表，`#/english-exams/<年份>` 原题作答。新增入口在首页原三个英语入口之后，也在英语试题库增加链接。
- 选择题按原选项判分，单词填空忽略大小写及首尾空白，兼容来源的斜杠备选答案和 `(s)`。无可靠答案显示当前作答但不评分、不增加错误次数。
- 答案及解析默认隐藏，提交或查看答案后显示；缺原解析明确标待补充，不假装已有解析。非官方回忆版始终标注。
- 分组 `english-exam:<年份>` 使用现有 `xq.english-progress.v1.<归属>` 与 `xq.errors.v2.<归属>`，结构不变，不升版本。按账号隔离，旧页面在账号变化后拒绝写入；数学进度不受影响。本功能不保存未提交草稿或整卷提交记录。
- 听力不自动播放，路由切换停止播放；服务器补充媒体 MIME。网页不依赖图片、PDF 或 Word 查看器，不用 fetch 或 CDN。

初次导入过程中复制的原件已移到本地忽略目录 `refs/english-past-papers/`，可恢复；运行目录只保留题目脚本与听力媒体。

## 验证

测试年份倒序与缺失年、题目 ID 唯一、选项/答案格式、文章完整性标记、原来源、pending 状态、回忆版和 2025 缺题提示、纯文本与下划线渲染、未答阻止提交、正确/错误/无答案判分、提交后显示解析、账号隔离及旧页面拒写、入口与 script 顺序。`node tests/run.js` 必须全绿。
