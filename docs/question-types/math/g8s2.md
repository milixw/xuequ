## 二、按小节明细

只列扩展和挑战题（基础题不易撞车）。

### 23.1 多边形（八年级下册）
2026-10-07 新做（按试读片段），真卷标尺，子代理盲解复核两轮通过。卡片“外角和是 360°”配 exteriorWalk；b04 解析也配 exteriorWalk。
- 本节的限制：梯形、平行四边形及特殊四边形的性质判定、中位线都没学；课本没有“正多边形”一词，题干写“各边都相等、各内角也都相等”
- 基础：凸多边形辨认 / 五边形求 $x$（外角坑）/ 内外角和之比 / 机器人转角 / 对角线总数 / 剪角三种 / 外角之比 / 两外角之和 / 说法辨析
- 扩展：除去两个内角 / 内角范围转外角不等式 / 四边形内外平分线 / 内角是 4 的倍数计数 / 四边形折叠 / 顶点圆面积差
- 挑战：内角依次增加整数度 / 剪成两块的 $\frac76$ 倍 / 边外侧尖角的存在性 / 内角两两不等的极值 / 五边形上等边三角形两种位置
- 复核意见：机器人转角题要限定路线是凸多边形（否则 $a=48$、$96$、$168$ 的星形也走 15 段）；n 角星角度和与平均值一步出的存在性只有 4～5 级；2340→13、剪角后 1440 是流传数据，要换

### 23.2 平行四边形（八年级下册）
2026-10-07 新做（按试读片段），真卷标尺，子代理盲解复核两轮通过。卡片“性质”配 parallelogramDrag，“中心对称”配 motion half；b08 解析也配 motion half。
- 本节的限制：矩形、菱形、正方形的性质判定和中位线都没学；按课本定义，梯形包括平行四边形
- 基础：概念辨析 / 对角之和求邻角 / 半周长求对角线 / 对角线一半 + 勾股 / 对角线上两点的判定条件 / 两条高夹角 / 面积换两个距离 / 过中心直线求周长 / 半对角线定边长范围
- 扩展：两条角平分线交直线 CD 分类 / 往返动点：平行四边形 + 面积 1:2 / 内部一点面积 / $AB=2AD$ 中点出直角 / 倍长中线 + 逆定理 / 三点求第四点
- 挑战：五个条件两两组合判定计数 / 对角线最短（垂足越界取端点）/ 两个等边三角形内外四种位置求面积 / 对角线是方程的根（共高两次勾股）/ 面积比定平行线 + 轴对称最短
- 复核意见：c03 原题（两个都向外作等边三角形证 $\triangle CEF$ 等边）只有 4 级且是流传老题，改成内外四种位置分类求面积；c05 配图 P 不在高 2 的直线上；e02 加面积比 1:2 一问补扩展档难度；c01 反例写全、反证只用外角

### 23.3 矩形、菱形与正方形（八年级下册）
2026-10-07 新做（按试读片段），真卷标尺，子代理盲解复核两轮通过。卡片“矩形和它的性质”配 quadFamily；b08、c04 解析配 motion 翻折。
- 本节的限制：按课本定义体系（矩形、菱形用四边形定义，再给“平行四边形 + 条件”判定）；中位线、重心、坐标系、相似、三角比、一元二次不等式不能用；“菱形对角线平分一组对角”课本没列为定理，题里用三线合一现推
- 基础：命题辨析 / 菱形比平行四边形多的性质 / 矩形对角线 120° 求边 / 菱形周长与对角线和求面积 / 菱形对角线上一点求角 / 正方形对角线上 $AE=AB$ / 平行四边形成矩形的条件 / 折出正方形 / 正方形加等边三角形两种位置
- 扩展：矩形中 $DE\perp AC$ 角的倍数 / 菱形内矩形对角线 + 垂线段最短 / 菱形对称求 $PE+PB$ 最小 / 直线 $AD$ 上的点到两条对角线距离（三段）/ 宽 3、4 纸条重叠面积分类 + 检验 / 菱形对角线上点使三角形等腰
- 挑战：外角平分线上的 $PE\perp AP$（截长全等 + 钝角等腰 + 配方）/ $PA=7$、$PB=6$、$PC=11$ 旋转求角、面积、$PD$ / 平分线围成矩形反求 $BC$（分类 + 一元二次方程）/ 矩形折叠 $A$ 到 $CD$ 上的取值范围 + 折痕长 / 正方形内接菱形面积最小
- 复核意见：AE 平分 ∠BAD、∠CAE=15° 求 ∠BOE=75° 与 PA=1、2、3 都是流传原题数据，要换；平分线围成矩形直接求面积只有 3～4 级，改反求加分类；60° 菱形折叠的 M 在 CD、BC 上都不受限制，取值范围题改用矩形；扩展档要有一道 5 级

### 23.4 三角形的中位线与重心（八年级下册）
2026-10-07 新做（按试读片段），真卷标尺，子代理盲解复核一轮通过。卡片“中位线定理”配 midlineRotate、“重心和重心定理”配 centroid；e01 解析配 varignon。
- 本节的限制：相似、比例线段、坐标系不能用；“过中点平行于一边的直线平分第三边”课本没讲，不用；重心的面积结论引用课本例 3，“六个小三角形面积相等”在题里现推
- 基础：概念辨析 / 截下四边形面积 / 直角三角形中位线 / 平行求角 / 由 GD 求中线 / 等边三角形 AG / 小三角形面积倒推 / 矩形中的中位线 / 重心到边距离
- 扩展：中点四边形辨析 / 外角平分线造中点 / 等腰三角形 BG 与到腰距离 / 高与三个中点 / 两边 6、8 分类 / 梯形两底
- 挑战：中点四边形面积最大 / 中线互相垂直 / 对边中点取对角线中点 / 平行四边形中的重心 / 直线 DE 上的直角三角形四解
- 复核意见：b04 配图顶点超出画布；中线互相垂直（6、8）和对边中点（6、8、两角和 90°）与网上流传题同数据，换成 4、7 和 10、24
