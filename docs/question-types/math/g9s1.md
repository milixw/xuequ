## 二、按小节明细

只列扩展和挑战题（基础题不易撞车）。

### 27.1 二次函数的概念
2026-10-08 新做，真卷标尺，子代理盲解复核两轮通过。
- 本节的限制：图像与性质（顶点、增减、最值）在 27.2，c01 的比较只用作差因式分解
- 扩展：含参类型+函数值 / 两个正比例合成 / 靠墙带隔断花圃 / 线段上的点围矩形换自变量 / 复合与加减 / 矩形内接四边形
- 挑战：团体票分段计价 / 指数含参三分类 / 矩形双动点分段 / 反比例与含参直线面积 / 参数运动路线与 y=kx
- 复核意见：分段去绝对值解两个方程、一步看出无解只有 4 级；平方项抵消的坑别在基础题里出两次

### 27.2 二次函数的图像与性质
2026-10-08 新做，真卷标尺，子代理盲解复核两轮通过。卡片配 parabolaShape、parabolaShift。
- 扩展：图像判断五结论 / 含参区间最大值 / 关于原点对称再平移 / 四边形面积 / 含参增减区间 / 顶点轨迹
- 挑战：[t,t+2] 最大减最小 / 对称轴上点等腰+直角 / 顶点在 y=x+1 上 △OPQ 面积=h² / 开口未知比大小 / 铅垂高最值+面积 1/5
- 复核意见：y=−x²+4x+5 配面积最大 125/8 是流传数据；单纯的三种等腰分类只有 4～5 级

### 27.3 确定二次函数的表达式
2026-10-08 新做，真卷标尺，子代理盲解复核两轮通过。卡片配 parabolaShift。
- 本节的限制：课本没有“交点式”名称，从按根分解推出 y=a(x−x₁)(x−x₂)
- 扩展：顶点到 x 轴距离分类 / 直线截距+对称轴 / 平行四边形第四顶点 / 平移后对称轴 / 面积分类 / 对应值表找错
- 挑战：反求区间 m、n / 等腰+钝角筛选 / 旋转 180° 成矩形、平行四边形 / 定点+等腰直角+与线段一个公共点 / 关于 x=t 对称+直角
- 复核意见：第一轮五道挑战题全被评为只到压轴；∠ACB=90° 求 C 再铅垂高是流传题换数

### 27.4 二次函数与一元二次方程
2026-10-08 新做，真卷标尺，子代理盲解复核两轮通过。卡片配 parabolaRoots。
- 本节的限制：课本没有“看图写 y>0 时 x 的范围”，不出二次不等式
- 扩展：一个公共点（含一次函数）/ x₁²+x₂²=7 舍根 / 区间内两根 / 斜线段公共点 / 弦长 / 过定点与距离
- 挑战：翻折图像与斜线 / 过定点与线段 OD / 面积相等的 P 个数 / ∠AOB 恒直角+OB=8OA / 与坐标轴恰两个公共点+距离最大值
- 复核意见：y=x² 与过 (0,1) 的直线 OA⊥OB 是流传原题数据，改成 y=½x² 与 y=kx+2

### 27.5 二次函数的简单应用
2026-10-08 新做，真卷标尺，子代理盲解复核两轮通过。卡片配 fenceArea。
- 本节的限制：二次不等式按“看图像在某条水平线上方的部分”讲，不用不等式解法
- 扩展：拱桥换建系+水位 / 斜坡上的球 / 墙长未知反求 / 降价促销让利 / 正方形双动点面积最小值 / 表格求一次函数+限价
- 挑战：涨降价两函数+进货上限 / 隔离带宽 d 两车并排 / 两地产能 / 过网落点含参 / 恰 3 个整数售价反求利润范围
- 复核意见：建系代点反求只有 4 级；卡片例子和基础题同设法同步骤就是换数版
