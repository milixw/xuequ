# 南通语文原题导入约定

2026-10-12 按用户要求暂时隐藏首页入口，已导入资料与路由保留，可直接访问 `#/nantong-chinese`。

`content/past-papers/nantong-chinese.js` 独立收录用户指定江苏目录中的南通语文资料，首页语文区 `#/nantong-chinese` 进入。试卷 ID 为 `nt-chinese-<年份>`，题 ID 为 `<试卷ID>-q<资料组号>`，复用主观题人工核对、按账号保存；不能把南通混入上海目录。来源文件名与 SHA-256 必须保留，整理版非官方、review 为 pending。题卷与答案分离，图片保留原图标注，无答案标待补充，不从答案编造原题。图片路径同现有格式，目录前缀使用 `nt-chinese`。

使用 `scripts/import-nantong-chinese.py <来源目录> <临时转换目录>`，依赖 python-docx、pypdf、Pillow。DOC 先在临时目录转成 DOCX，2023 扫描 PDF 在临时目录渲染六页 PNG。脚本拒绝覆盖已有数据。已核对七年共36组；2013答案为三张原照片，2020整卷图片的第7张在像素 y=1340 分离题干与答案，2023只有题卷，缺答案明确声明。DOCX 保留下划线、波浪线、加点与表格行列，已核实的学科网水印不作为题图。段落分组索引绑定本次转换文件哈希，不泛用于未核对版本。

2020 和 2023 图片卷各按整卷一组，按原题号输入答案；其余五年按知识与阅读材料分组，题组号不冒充官方小题号。2020 bbox 使用原图像素并标 `coordinateUnit: source-pixel`。原资料与临时转换文件留在来源目录和临时目录，不作为网页链接；发布文件只有 script 数据和必要原图。
