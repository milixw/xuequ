# 项目长期记忆（xuequ）

## 语文古诗文朗读音频：官方来源与版权边界

- 官方公益资源 = **中小学语文示范诵读库**（中央广播电视总台＋教育部＋国家语委联合打造，
  列入《国家语言文字事业"十三五"发展规划》）。内容为**义务教育阶段国家统编语文教材全部课文**，
  总台播音员录制、专家审听。分四批上线：2018 第一批，2020 第二、三批，2024-05-29 第四批 300 余篇。
- 免费**在线收听**入口：
  - 央广网专题页 `http://edu.cnr.cn/eduzt/ywkwsfsd/`（网页直接听，显示篇目与朗读者）
  - 云听 App（总台官方音频平台）搜索"中小学语文示范诵读"，有 1—12 年级各册专辑，**App 内可缓存离线**
  - 中国语言文字数字博物馆（语博）`https://szyb.smartedu.cn` 及语博 App
  - 央视新闻／央视频／央视网／国际在线／教育部网站／学习强国"中国语言文字"号
- 上海市教委官网 2024-09-03 转发过第四批上线消息（`edu.sh.gov.cn`）。
  上海初中用统编教材，61 篇必背全部出自统编六上～九下，与诵读库对口。
- **版权红线**：官方只提供在线收听，网页无下载按钮；音频版权归总台/教育部。
  第三方网盘（百度网盘、夸克、ABC教育资源网等）流传的教材配套 mp3 属未授权传播，
  **不下载、不入库、不转发**；个人离线自用走云听 App 缓存。
  若要在页面加朗读入口，只加官方页面**外链**，不把音频文件放进仓库。
