# 函数轨道

一款面向初中生的函数图像解谜手机网页游戏。

调整函数的参数，函数图像会跟着变化；按下"发射"，小球沿图像前进。要让小球**吃到所有星星、避开障碍物、落在终点旗帜上**。在玩的过程中理解 k、b、a、h 这些参数到底在控制什么。

## 快速开始

不需要安装任何依赖，也不需要构建。

**电脑上玩**：直接用浏览器打开 `index.html`。

**手机上玩**：

```bash
python3 -m http.server 8000     # 在项目目录下启动服务器
ipconfig getifaddr en0          # 查看电脑的局域网 IP（macOS）
```

手机连上和电脑同一个 Wi-Fi，用浏览器打开 `http://<电脑IP>:8000`。

## 当前关卡

| 关卡 | 函数 | 可调参数 | 知识点 |
|---|---|---|---|
| 1 认识截距 b | y = kx + b | b | 直线与 y 轴的交点是 (0, b) |
| 2 认识斜率 k | y = kx + b | k | x 每增加 1，y 变化 k |
| 3 k 也可以是负数 | y = kx + b | k、b | k < 0 时直线下降；两点确定一条直线 |
| 4 穿过缝隙 | y = kx + b | k、b | 经过同一点的直线有无数条，再加条件筛选 |
| 5 抛物线登场 | y = a(x − h)² + k | a | a 决定开口方向和大小 |
| 6 跳过高墙 | y = a(x − h)² + k | a、h、k | 顶点式与顶点 (h, k) |

过关进度保存在浏览器本地，刷新页面不会丢失。

```
CLAUDE.md    给 AI 编程助手看的项目说明和约定
```

## 新增或修改关卡

关卡是 `game.js` 里 `LEVELS` 数组中的一个对象，数据格式见 [CLAUDE.md](CLAUDE.md#关卡数据格式)。改完后运行：

```bash
node test.js
```

脚本会穷举每一关的所有参数组合，检查：

- 参考解（`solution`）能过关
- 初始参数（`init`）不能直接过关
- 参考解没有改动本关固定的参数

同时列出每关的全部可行解，方便确认解是否唯一。
