# 学趣闯关

面向初中生的**开源**学习闯关手机网页：按课本章节，每一节提供**通俗的知识点介绍 + 分三档难度的练习题**，自动判分，每道题都有分步解析。

## 宗旨

- **有乐趣**：闯关式练习、趣味玩法，数学概念尽量讲成学生能懂的话
- **有梯度**：每节 基础 5 道 → 扩展 10 道 → 挑战 5 道。挑战题难在思维，不靠超纲
- **看得见**：几何、立体几何、函数这类要靠想象的内容，用可以拖动、旋转、展开的图形帮学生“看见”问题（正在建设，见[路线图](#路线图)）
- **开放**：代码和内容都开源，出题流程公开，欢迎老师和同学一起纠错、补充

> 题目和知识点由 AI 编写，经过自动校验和独立的盲解复核，但**还没有经过老师审核**，界面上会标注“待审核”。发现错误欢迎[提 Issue](../../issues/new/choose)。

## 快速开始

不需要安装依赖，也不需要构建。

**电脑上用**：克隆仓库后，直接用浏览器打开 `index.html`。

**手机上用**：

```bash
./scripts/start.sh      # 后台启动本地服务器（需要 node），会打印手机要访问的地址
./scripts/stop.sh       # 用完后关闭
```

手机和电脑连同一个 Wi-Fi，用浏览器打开脚本打印的地址。

## 功能

- **首页 → 册 → 章节 → 小节**：先看知识点卡片（含例子和易错提醒），再挑题练习；首页右上角可以切换学期
- **真题卷**：册页面里列出本册的真题卷，按教材小节分组练习
- **限时测试**：按小节限时答题（基础每题 1 分钟、扩展 2 分钟、挑战 3 分钟），交卷后看分数和解析，考试记录按账号保存
- **题型**：单选、多选、填空。填空支持数值（分数、小数、带分数都能判）、多个答案（与顺序无关）、代数式（判断等价，可以要求“已化简”）、实数（根号、立方根、π）、角度（度分秒）、符号（> < =）
- **演示动画**：纸条对折、剪绳子、数轴折叠等题目在解析里有可以暂停、重播、慢放的动画
- **快捷输入栏**：手机上不方便输入的 − / ° ′ ″ 和字母，点一下就能插入
- **做题进度**保存在浏览器本地，题目方块用颜色区分：答对、答错过、看过解析、未做
- 纯静态网页，没有后端、不收集任何数据。“账号”只是在本机浏览器里区分不同的人（无密码），数据都存在浏览器本地

## 内容是怎么做出来的

AI 出的题最容易错在答案本身，所以每一节都要过这几关：

1. **限定知识范围**：按教材目录整理每章的知识范围（[docs/textbooks/](docs/textbooks/)），题目和解析都不能用还没学的方法
2. **自动校验**：题量配比、字段、公式渲染；标准答案要能被判分器判对；能计算的题用独立的 `verify` 函数重新算一遍
3. **盲解复核**：导出不含答案的题单，交给另一个 AI 独立解题并评估难度，不通过就改，第 1 章每节都复核了 3 轮
4. **老师审核**：上线前由数学老师审核（进行中）

完整流程见 [docs/sop-section.md](docs/sop-section.md)，已用的出题套路见 [docs/question-types.md](docs/question-types.md)，项目约定见 [AGENTS.md](AGENTS.md)。

## 项目结构

```
index.html          应用入口
src/                应用代码（判分、进度、做题引擎、限时测试、账号、演示动画、页面、小游戏）
content/            学习内容：catalog.js 是目录，每个小节一个文件
  math/sh2024/g6s1/ 上海 2024 版数学六年级上册
  math/sh2024/g8s1/ 上海 2024 版数学八年级上册
  exams/            真题卷，一份试卷一个文件
vendor/katex/       数学公式排版（本地副本，不走 CDN）
tests/              自动校验
scripts/            本地服务器、打包、部署
docs/               出题流程、题型台账、教材知识范围、限时测试说明、设计文档、部署说明
```

## 校验

```bash
node tests/run.js
```

检查判分逻辑、每个小节的题量和字段、公式渲染、标准答案自检、`verify` 独立计算、账号和限时测试逻辑，以及函数轨道每一关都有解。
