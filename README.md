# 学趣闯关

面向初中生的学习闯关手机网页应用：按课本章节，每一节提供**通俗的知识点介绍 + 分级练习题**（基础 5 道、扩展 10 道、挑战 5 道），可以自动判分，每道题都有分步解析。

当前内容：上海教育出版社 2024 版（五·四学制）数学六年级上册，第 1 章（1.1～1.5）已上线，其余章节正在制作中。另附一个"函数轨道"小游戏。

> 题目和知识点由 AI 编写，经过自动校验和独立盲解复核，但**还没有经过老师审核**。

## 快速开始

不需要安装依赖，也不需要构建。

**电脑上用**：直接用浏览器打开 `index.html`。

**手机上用**：

```bash
./scripts/start.sh      # 后台启动服务器，会打印手机要访问的地址
./scripts/stop.sh       # 用完后关闭
```

手机连上和电脑同一个 Wi-Fi，用浏览器打开脚本打印的地址。换了网络后电脑的 IP 可能会变，以脚本打印的为准。

## 功能

- **首页 → 册 → 章节 → 小节**，小节页先看知识点卡片（含例子和易错提醒），再选题练习
- **题型**：单选、多选、填空。填空支持数值（分数、小数、带分数都能判）、多个答案（与顺序无关）、代数式（判断等价，可以要求"已化简"）、角度（度分秒）、符号（> < =）
- **快捷输入栏**：手机上不方便输入的 − / ° ′ ″ 和字母，点一下就能插入
- **做题进度**保存在浏览器本地，题目方块用颜色区分：答对、答错过、看过解析、未做
- 题目可以随意挑着做；函数轨道的关卡也可以任意选，不按顺序解锁

## 项目结构

```
index.html          应用入口
src/                应用代码（判分、进度、做题引擎、页面）
content/            学习内容：catalog.js 是目录，每个小节一个文件
  math/sh2024/g6s1/ 上海 2024 版数学六年级上册
vendor/katex/       数学公式排版（本地副本）
tests/              自动校验
docs/               开发计划、教材目录与知识范围
```

详细说明和内容编写规范见 [CLAUDE.md](CLAUDE.md)，制作小节的流程见 [docs/sop-section.md](docs/sop-section.md)。

## 部署到服务器

```bash
./scripts/build.sh     # 打包（先跑校验），产物在 dist/
```

上传解压后 `./run.sh start` 即可，详见 [docs/deploy.md](docs/deploy.md)。

## 校验

```bash
node tests/run.js
```

会检查：

- 判分逻辑（分数、代数式等价、角度等）
- 每个小节的题量和难度配比、字段是否齐全、公式能否正常渲染
- 标准答案本身能否被判分器判对
- 能计算的题目，用独立的计算（`verify`）核对答案
- 函数轨道小游戏的每一关都有解
